## 摘要
多轮推理与行动（ReAct）智能体会积累不断增长的推理、工具调用和观察轨迹。它们的键值（KV）缓存也随之增长，在模型推理过程中增加内存使用和注意力成本。现有的KV缓存压缩方法通过驱逐低注意力分数的状态来降低这些成本。然而，当前轮次中的低注意力并不意味着未来不相关，因为暂时不活跃的信息之后可能变得重要。因此，基于快照的驱逐方法并未明确区分暂时休眠的信息与似乎已完成其角色的信息。在本文中，我们提出了CommitKV，它通过提交转换来识别KV生命周期。具体而言，CommitKV首先将已完成的智能体事件划分为令牌页面，并在工具调用提交之前以及提交返回的观察结果已被纳入之后，比较每个合格页面的删除效果。基于这些配对测量，CommitKV将休眠页面与从高到低的完成候选项区分开来。然后，它应用贪心联合测试，仅当候选页面的提交后组合效果保持有界时，才接受其退役。最后，在后续的压缩检查点，排除已接受的页面，保护一组等待提交后测量的有界页面，并使用相同的令牌索引为键、值和绝对位置在缓存预算内保留剩余的KV状态。这些机制确保CommitKV能够区分休眠信息与已完成其观察角色并可安全移除的信息。在各种基准测试上的实验表明，CommitKV减少了智能体的内存使用，加速了端到端推理，并比现有的KV缓存压缩方法实现了更高的准确性。

## Abstract
Multi-turn Reasoning-and-Acting (ReAct) agents accumulate growing trajectories of reasoning, tool calls, and observations. Their key-value (KV) caches grow accordingly, increasing memory use and attention cost during model inference. Existing KV cache compression methods reduce these costs by evicting states with low attention scores. However, low attention in the current turn does not imply future irrelevance, as temporarily inactive information may become important later. Snapshot-based eviction methods therefore do not explicitly distinguish temporarily dormant information from information that appears to have completed its role. In this paper, we present CommitKV, which identifies KV lifecycles through commit transitions. Specifically, CommitKV first divides completed agent events into token pages and compares each eligible page's deletion effect before a tool-call commit and after the commit's returned observation has been incorporated. Based on these paired measurements, CommitKV distinguishes dormant pages from high-to-low completion candidates. It then applies a greedy joint test, accepting candidates for retirement only when their combined post-commit effect remains bounded. Finally, at a later compression checkpoint, accepted pages are excluded, a bounded set of pages awaiting post-commit measurement is protected, and the remaining KV states are retained within the cache budget using the same token indices for keys, values, and absolute positions. These mechanisms ensure that CommitKV can distinguish dormant information from information that has completed its observed role and can be safely removed. Experiments on various benchmarks show that CommitKV reduces agent memory use, accelerates end-to-end inference, and achieves higher accuracy than existing KV cache compression methods.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **研究背景**：多轮 ReAct（Reasoning-and-Acting）智能体通过交替执行推理、工具调用和观察结果处理来解决复杂任务。随着交互轨迹的增长，其 KV（Key-Value）缓存持续累积，导致模型推理时内存占用和注意力计算成本不断增加。虽然跨轮 KV 复用避免了重复预填充完整历史，但持久化的缓存仍使内存和延迟问题日益突出。
- **核心矛盾**：现有 KV 缓存压缩方法（如 SnapKV、R-KV、TriAttention）普遍基于**快照式评分**——根据当前轮次的注意力分数或查询相关性估计 token 重要性，并驱逐低分 token。但这种策略存在根本性盲区：**当前轮次的低注意力并不代表未来无关**。一个暂时休眠（dormant）的信息页可能在后续轮次重新变得关键，而一个已完成作用的工具调用页则可能安全移除——两者在当前快照下可能表现出相同的低重要性，但未来命运截然不同。
- **核心问题**：快照式驱逐方法无法区分"暂时休眠"与"已完成角色"两类低影响信息，容易导致有用 KV 状态被过早驱逐，损害智能体在长轨迹任务中的性能。
- **论文目标**：提出一种**生命周期感知**（lifecycle-aware）的 KV 缓存压缩方法 CommitKV，通过工具调用提交（commit）前后的配对观测来识别 KV 状态的生命周期阶段，从而安全地区分可退役信息与需保留信息。

## 2. 论文提出的方法论（核心思想与技术细节）

### 2.1 核心思想

- **工具调用提交（commit）作为生命周期边界**：将每次工具调用生成的结束节点视为一个"提交"（commit c），提交前后分别对应观察结果返回前后的两个查询窗口。
- **提交转换（commit transition）**：对同一个事件页（event page），分别测量其在提交前和提交后（观察结果被纳入下一轮输入后）的删除效应（deletion effect），通过前后状态的对比判断该页面的生命周期归属。
- **核心洞察**：**高 → 低（HIGH→LOW）**的转换说明页面已完成其观察到的角色（completion candidate）；**低 → 低（LOW→LOW）**则说明页面仅是暂时休眠，不应据此驱逐。

### 2.2 关键技术细节

**（1）事件页划分与配对查询窗口**

- 将完成的工具调用 \(a_i\) 和返回观察 \(o_i\) 各自划分为连续的事件页（event page）\(E\)，每页长度 \(|E| \le G\)（实验中 \(G=16\)）。
- 对工具调用 commit \(c\)，定义配对查询窗口：
  - 提交前窗口 \(Q_c^- = \{|y_t| - W + 1, \ldots, |y_t|\}\)：工具调用生成结束前的最后 \(W\) 个解码查询位置。
  - 提交后窗口 \(Q_c^+ = \{|x_{t+1}| + 1, \ldots, |x_{t+1}| + W\}\)：观察结果加入后下一轮的前 \(W\) 个解码查询位置。
- 两个窗口分别捕获观察结果纳入前后的注意力读取模式。

**（2）删除效应测量**

- 对单个注意力头，删除事件页 \(E\) 的 token 并重新归一化剩余注意力权重，计算注意力输出变化：
  \[
  o_{\setminus E}^p = \frac{o_p - \sum_{i \in E, p_i \le p} a_{p_i} v_i}{1 - \sum_{i \in E, p_i \le p} a_{p_i}}
  \]
- 在查询窗口 \(Q\) 上取最大相对输出变化，再跨头取最大：
  \[
  R(E; Q) = \max_h \max_{p \in Q} \frac{\|o_p - o_{\setminus E}^p\|_2}{\|o_p\|_2}
  \]
- 分别计算提交前删除效应 \(R_c^-(E)\) 和提交后删除效应 \(R_c^+(E)\)。

**（3）生命周期状态分类（结合绝对效应与百分位）**

- 对每个候选页 \(E\)，同时计算绝对删除效应 \(R_c^\pm(E)\) 和百分位秩 \(P_c^\pm(E)\)。
- 双重条件判定高/低状态：
  - **高状态**：\(R_c^\pm(E) \ge \tau_{use}\) 且 \(P_c^\pm(E) \ge \rho_{use}\)
  - **低状态**：\(R_c^\pm(E) \le \tau_{dead}\) 且 \(P_c^\pm(E) \le \rho_{dead}\)
- 生命周期分类结果：
  - **completion candidate（完成候选）**：\(H_c^- = 1\) 且 \(L_c^+ = 1\)（高→低）
  - **dormant（休眠）**：\(L_c^- = 1\) 且 \(L_c^+ = 1\)（低→低）
  - **newly active（新活跃）**：\(L_c^- = 1\) 且 \(H_c^+ = 1\)（低→高）
  - **still active（持续活跃）**：\(H_c^- = 1\) 且 \(H_c^+ = 1\)（高→高）
  - **uncertain（不确定）**：其余情况
- 只有完成候选进入退役流程；休眠页被保留。

**（4）贪心联合验证构建退役集**

- 完成候选按 \(R_c^+(E)\) 升序、\(R_c^-(E)\) 降序排序（优先选择提交后影响小、提交前影响大的页面）。
- 逐个候选加入退役集 \(D_c\)，但需满足联合删除效应约束：
  \[
  R_c^+(D_c \cup \{E\}) \le \tau_{joint}
  \]
- 联合验证防止多个页面单独删除影响小而合并删除影响过大的累积效应。

**（5）待测页保护机制**

- 提交后测量状态尚未收集的页面（pending pages）在压缩检查点必须保留，否则无法完成提交转换配对。
- 保护页面数量受限：\(|N_j| \le B_N = \lfloor \eta B \rfloor\)（实验 \(\eta = 0.125\)）。
- 超出保护预算时，优先保护 \(R_c^-(E)\) 更大的页面（强提交前效应是识别高→低转换的前提）。

**（6）固定预算压缩**

- 在压缩检查点 \(j\)：排除退役集 \(D_c\) 的 token、保护待测页 \(N_j\)、从其余 resident tokens 中按预算 \(B\) 选择保留子集 \(I_j\)。
- 相同索引 \(I_j\) 同时应用于 keys、values 和绝对位置，确保 RoPE 位置编码的一致性。

**（7）算法流程（Algorithm 1）**

- 逐轮进行：预填充（第一轮问句或后续观察）→ 解码 → 在下一轮首次测量提交后效应 → 生命周期分类 → 联合验证构建退役集 → 新一轮提交时测量提交前效应并保护 pending 页 → 压缩检查点时执行索引压缩。

- **准确率领先**：在 4096 token 预算下，CommitKV 在 3 个主模型上分别比最强压缩基线高 **19.85%（Qwen3-14B）**、**5.49%（Qwen3.6-27B）** 和 **1.54%（DeepSeek-R1-Distill-Llama-8B）** 的平均准确率。

- **整体结论**：生命周期感知的缓存退役可以有效区分布安全性不同的低影响信息，在显著降低内存与延迟的同时保持智能体任务性能。

## 8. 不足与局限

- **与 FullKV 的差距未完全消除**：即使在最优设置下，CommitKV 在多数基准上仍低于 FullKV 的性能，论文也承认"在较小缓存预算下与 FullKV 的差距是未来要解决的剩余问题"。
- **依赖结构化工具调用轨迹**：方法的前提是 ReAct 式工具调用 + 观察返回的显式边界。对于不涉及工具调用的纯对话或单轮长文本任务，提交转换的语义可能不成立，适用范围受限。
- **仅依赖单层注意力**：删除效应只在一个注意力层上计算，未验证不同层位选择对结果的敏感性；不同模型的注意力分布差异可能影响通用性。
- **保护预算相对粗糙**：待测页保护采用固定分数 \(\eta B\) 和固定页数上限，未考虑不同任务流量下待测页数量动态变化对保护完整性的影响，极端情况下待测页可能超出保护预算而被截断。
- **实验覆盖的局限**：
  - 对比方法局限于驱逐类压缩，未覆盖量化、合并、低秩投影等其他主流压缩路线。
  - 未报告小样本数据集（如 AIME25 仅 30 题）的方差或重复实验。
  - 未提供不同模型家族（如 GPT-OSS、InternLM3）在正文中的详细分解表，主结论主要依赖中大规模模型。
- **缺乏可复现细节**：论文未开放代码/配置链接，超参数（如 \(\tau\)、\(\rho\) 的刻度选择）的选取依据和敏感性分析仅通过消融实验间接

- **缺乏可复现细节**：论文未开放代码/配置链接，超参数（如 \(\tau_{use}\)、\(\tau_{dead}\)、\(\rho_{use}\)、\(\rho_{dead}\) 的刻度选择）的选取依据和敏感性分析仅通过消融实验间接体现，未以网格搜索或阈值扫描等方式直观量化这些参数对性能的影响强度，读者难以清晰判断该方法在不同阈值下的稳健性和最佳实践范围。

## 9. 启发与展望

- **可推广的场景扩展**：生命周期思想虽以“工具调用提交”为锚点，但其“配对前后状态对比”的框架具有一定的通用性。未来可探索将“提交”概念类比为文档切换、流程阶段切换、角色交替等对话结构事件，将方法推广到非 ReAct 工具的日常多轮对话、长文档多阶段问答等场景，以突破当前对结构化工具轨迹的依赖。
- **压缩粒度的进一步细化**：当前方法以“事件页”（页长 \(G=16\)）为基本压缩单元，页粒度折中了解析精度与开销。未来可考虑页内 token 级细化，或结合模型置信度对保护预算进行自适应分配，使退役决策从“固定页”走向“动态分组”，进一步提升缓存利用效率。
- **多种压缩路线的融合前景**：CommitKV 当前聚焦于驱逐类压缩，与量化、合并、低秩分解等压缩手段属于正交方向。后续工作可研究将生命周期感知的驱逐与量化/合并相结合，在不同维度上同时压缩缓存，在极限预算下进一步逼近 FullKV 的能力上限。
- **轻量化与在线自适应**：生命周期判定依赖逐 commit 扫描和配对测量，虽然成本可控，但在极高频率工具调用或超长上下文场景下仍可能产生额外开销。未来可探索用轻量预测模型或运行时的统计特征自动估计页面的生命周期状态，减少重复扫描与验证的次数，提高实际系统的吞吐表现。
- **超参数的自适应化**：绝对阈值与百分位阈值的组合灵活但刻度敏感，未来若能结合任务类型或缓存容量压力自动调节阈值，将更好地适应不同预算、不同模型、不同任务分布的多样化需求。

## 10. 总体评价

- **问题发现极具价值**：论文指出的“快照式压缩在工具调用场景下的结构性盲区”是真实且关键的问题，为多轮智能体 KV 缓存管理提供了一个此前被忽视的视角。
- **方案完整度高**：从状态分类到验证退役再到保护机制，CommitKV 在方法层面形成了严谨的闭环，各环节设计相互支持，不仅性能上对现有基线有明显优势，也使读者能清晰理解每一项设计的目的与作用。
- **实验证明力在同类工作中属前列**：多模型、多基准、多预算、效率实测与逐组件消融的组合，使结论具有较强的可信度；但可复现资源（代码/配置未开放）和部分边缘数据集上的统计稳健性仍是薄弱环节。
- **综合来看**：CommitKV 是一篇问题意识明确、方法论具有原创性、实验验证比较扎实的推理时 KV 压缩工作，对多轮智能体场景下的内存-性能权衡提供了新的解决思路，也为后续研究打开了“生命周期感知”这一全新的方法论方向。若能在代码开源、超参数敏感性分析和跨语言/非工具场景的泛化性上进一步完善，其影响力与实用性还将显著提升。
