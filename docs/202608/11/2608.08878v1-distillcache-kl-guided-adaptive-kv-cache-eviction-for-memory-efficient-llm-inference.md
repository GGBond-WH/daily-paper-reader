## 摘要
基于Transformer的大型语言模型（LLM）在许多任务上表现优异，但其键值（KV）缓存随序列长度线性增长，成为长上下文推理中严重的内存瓶颈。现有启发式淘汰方法（如H$_2$O和SnapKV）依赖静态注意力或位置信号，往往无法捕捉token未来的预测影响力。我们提出DistillCache，一种将KV缓存淘汰建模为序贯决策问题的强化学习框架。DistillCache利用丰富的内部模型信号（注意力统计量、值范数、熵和位置）学习轻量级策略网络，并通过REINFORCE算法使用每步KL散度奖励进行训练，以保持完整缓存的输出分布。在7B参数指令微调Transformer（Mistral-7B-Instruct-v0.3）上，DistillCache在25%缓存预算下于LongBench上保留了完整缓存准确率的94.2%，比强启发式基线（H$_2$O、SnapKV）高出最多2.7个绝对百分点，并且在长上下文任务上比我们重新实现的并发基于RL的方法（ForesightKV、RLKV）高出最多1.4个百分点。在推理基准上，DistillCache与最优并发方法相当，并在激进压缩下超越之。它还实现了最高2.1倍的完整缓存吞吐量，同时保持有竞争力的实际效率。这些结果凸显了学习型、分布感知策略在内存高效长上下文LLM推理中的有效性。

## Abstract
Transformer-based large language models (LLMs) achieve strong performance across many tasks, but their Key-Value (KV) cache grows linearly with sequence length, creating a severe memory bottleneck for long-context inference. Existing heuristic eviction methods (e.g., H$_2$O and SnapKV) rely on static attention or positional signals that often fail to capture a token's future predictive influence. We propose DistillCache, a reinforcement learning framework that formulates KV-cache eviction as a sequential decision problem. DistillCache learns a lightweight policy network using rich internal model signals (attention statistics, value norms, entropy, and position) and trains it with REINFORCE via a per-step KL-divergence reward to preserve the full-cache output distribution. On a 7B-parameter instruction-tuned Transformer (Mistral-7B-Instruct-v0.3), DistillCache retains 94.2% of full-cache accuracy on LongBench at a 25% cache budget, outperforming both strong heuristic baselines (H$_2$O, SnapKV) by up to 2.7 absolute points and, under our re-implementations, concurrent RL-based methods (ForesightKV, RLKV) by up to 1.4 points on long-context tasks. On reasoning benchmarks, DistillCache is competitive with the best concurrent method and surpasses it under aggressive compression. It also delivers up to 2.1x full-cache throughput while maintaining competitive practical efficiency. These results highlight the effectiveness of learned, distribution-aware policies for memory-efficient long-context LLM inference.

- **核心洞见**：缓存淘汰本质上是一个**序贯决策问题**——每个解码步的选择会影响后续所有步的生成质量，因此适合用强化学习（RL）来端到端优化长期效用，而非依赖静态代理信号。
- **整体含义**：论文提出将KV缓存淘汰从启发式规则驱动转向**学习式、分布感知的策略驱动**，以显式内存预算为约束、以"保留全缓存输出分布"为目标，为内存高效的长上下文LLM推理提供了一种新范式。

### 2. 提出的方法论

#### 2.1 核心思想

将KV缓存淘汰建模为**马尔可夫决策过程（MDP）**：在每个解码步，策略网络根据当前缓存中每个token的内部特征打分，选择保留预算内的token子集；奖励信号为**全缓存（teacher）与剪枝缓存（student）下一token分布的KL散度负值**，直接优化保留决策对输出分布保真度的影响。

#### 2.2 关键技术细节

| 组件 | 设计 |
|------|------|
| **状态空间** | 每个token的特征向量 \(x_i \in \mathbb{R}^5\)：平均注意力质量（αᵢ）、值向量ℓ2范数、跨头注意力方差（σᵢ）、注意力加权熵（Hᵢ）、归一化位置（posᵢ） |
| **动作空间** | 策略网络输出每个token的标量分数，训练时通过Gumbel噪声扰动产生随机排名，取Top-B子集（服从Plackett–Luce分布）；推理时确定性Top-B选择 |
| **训练架构** | 双缓存设计：**teacher缓存**（从不剪枝，提供全缓存分布Pₜ）与**student缓存**（按策略剪枝，提供剪枝分布P̂ₜ），KL散度即为奖励 |
| **奖励函数** | \(R_t = -D_{KL}(P_t \| \hat{P}_t)\)，且论文通过理论推导证明了每步KL散度被驱逐注意力质量的平方所上界约束 |
| **策略优化** | REINFORCE + 折扣回报（γ=0.99）+ 熵正则（β=0.01）+ RLOO（leave-one-out）基线 + 指数滑动平均基线；log-partition函数用动态规划精确计算（O(L·B)复杂度） |
| **推理流程** | 单次前向传播即可完成：生成logits → 提取特征 → 策略打分 → 剪枝缓存供下一步使用；当前token由未剪枝的logits决定，剪枝不直接影响当前预测 |

#### 2.3 理论动机

论文证明：若被驱逐token的注意力质量为εₜ且值范数有界，则输出logit扰动和KL散度均被εₜ的相关函数上界约束。这为用KL散度作为奖励提供了理论依据，同时KL奖励通过完整softmax端到端捕捉保留token之间的非线性交互，超越了线性注意力界。

### 6. 主要结论与发现

- **性能领先**：在Mistral-7B-Instruct-v0.3上，25%缓存预算下LongBench保留**94.2%**全缓存准确率（39.1 vs 41.5），较H₂O高+2.7点、SnapKV高+2.1点、ForesightKV高+0.9点、RLKV高+1.4点。
- **激进压缩优势**：12.5%预算下LongBench仍有88.2%相对准确率，优势进一步扩大；推理任务亦在激进压缩下反超RLKV。
- **理性基准竞争力**：在中等预算（50%/25%）的推理任务上，RLKV略优于DistillCache（如25%时45.7 vs 45.0），但在12.5%最激进压缩下DistillCache反超（39.9 vs 38.9）。
- **长上下文鲁棒性**：8K上下文时DistillCache（38.1）显著领先所有基线（RLKV为36.4），优势随上下文长度增加而扩大。
- **吞吐量**：25%预算下约2.1倍全缓存速度提升（38 tokens/s vs 18 tokens/s），但比H₂O低约4.8 tokens/s，开销主要来自特征提取（+0.9 ms）和策略推理（+0.5 ms）。
- **零样本跨模型迁移**：Mistral上训练的策略迁移到Llama-3-8B无需微调，仍优于原生启发式基线，且避免了并发RL方法需逐模型重训的成本。
- **行为特征**：学到的策略自动恢复注意力汇聚token和近期token保护（类似H₂O/StreamingLLM），同时额外保留关键否定词和从句动词等分布关键token。

### 7. 优点

- **目标函数具有理论支撑**：从注意力输出线性性出发，严格推导了被驱逐注意力质量与KL散度的上界关系，奖励设计有据可依，而非纯经验驱动。
- **分布保真导向**：直接优化每步输出分布的KL散度，比启发式注意力统计或最终答案正确率更通用，天然覆盖低熵易受攻击token的脆弱性。
- **轻量级部署**：策略仅约200K参数，推理时仅在单次前向传播基础上增加约1.4 ms/token，实现接近启发式方法的实际效率。
- **丰富特征工程**：5维特征组合覆盖注意力、值语义、熵和位置多维信息，显著超越单用注意力特征的简化变体（+2.6点）。
- **零样本跨模型能力**：展示策略学习了一般性token保留模式，具备跨架构迁移潜力，有助于摊销训练成本。
- **诚实和透明**：对并发方法的比较明确标注为"最佳努力重实现"，不夸大为权威排名；同时提供低熵token自动高惩罚的机制解释。
- **正交可组合性**：与头部级方法（RLKV）混合可进一步提升（+0.7点），与offloading、量化、算子优化等系统技术互补。

### 8. 不足与局限

- **训练成本高**：约130 GPU小时 + 双倍内存占用（双缓存），显著高于零训练的启发式方法。策略每token独立打分，未显式建模token间交互依赖。
- **REINFORCE方差**：尽管采用RLOO基线+熵正则缓解，但REINFORCE本质仍具较高方差，PPO/GRPO等更先进优化器可能提升稳定性但会大幅增加复杂度。训练需5个随机种子取平均，也侧面反映方差控制是挑战。
- **推理开销**：约+1.4 ms/token的特征提取+策略评估开销，使其吞吐量低于H₂O/SnapKV约4-5 tokens/s；内核融合可缓解但尚未实现。
- **并发基线比较偏差风险**：与ForesightKV、RLKV的对比基于重实现而非官方代码，训练设置和超参调优差异可能影响精确差距；论文自己也承认RLKV在中等预算推理任务上仍具优势。
- **架构泛化限制**：特征设计（注意力统计、值范数等）与Transformer注意力机制强耦合，迁移到非Transformer架构需重新设计。
- **中等推理预算差距**：在推理基准的中等预算档（50%/25%），RLKV的头部级门控策略表现更优，说明推理任务与通用长上下文任务的最优策略可能存在本质差异，DistillCache并非在所有场景下全面领先。
- **实验规模有限**：仅覆盖7B-8B模型、最长8K上下文，未验证更大模型（13B+）和超长上下文（32K-128K）的可扩展性；训练需在≤4,096 token序列上进行，超过此长度时精确log-partition计算（O(L·B)）代价可能过高。
