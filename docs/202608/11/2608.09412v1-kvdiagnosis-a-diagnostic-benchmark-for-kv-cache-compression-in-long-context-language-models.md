## 摘要
KV缓存压缩可减少长上下文内存占用，但聚合任务分数既无法揭示哪些正确执行失败了，也无法说明失败原因。我们提出了KVDiagnosis，一个诊断数据集和基准，包含三项贡献。首先，一个包含25种方法的分类法将方法归为五个机制家族，并将它们与八个经过验证的实现及其有效的诊断测量联系起来。其次，对于每种受支持的方法设置，我们在每个固定划分中评估所有数据源，并与每个数据源的FullCache对照进行比较，然后针对每种方法设置分别选择FullCache正确/压缩错误（C-to-W）的行，因此没有任何压缩器定义另一个压缩器的测试集。第三，一种通用记录格式将成对输出和运行元数据与缓存、似然、注意力和解码测量联系起来，并带有明确的适用性状态。在Qwen3-8B上，四个证据感知工作负载在2600个数据源上产生了59,800次受支持的压缩运行和12,520个C-to-W行。在固定的诊断规则下，63.2%的运行具有低或部分测量/预计覆盖率。仅19行（0.2%）兼具高测量/预计覆盖率和强似然漂移；另有2,126行（17.0%）保留了结构位置可寻址性，其表示保真度仍未知，同时表现出相同的漂移。与C-to-C成功对照相比，所有十项诊断都能区分失败与成功的压缩（分层AUROC为0.684-0.871）。在96个可复现的低EAR失败中，受控的4倍证据-注意力提升修复了29.2%，而计数匹配的假干预修复了6.3%，匹配的C-to-C对照则恶化了3.3%。代码和数据可在 https://github.com/ChosenQC/KVDiagnosis 获取。

## Abstract
KV-cache compression reduces long-context memory, but aggregate task scores reveal neither which correct executions fail nor why. We present KVDiagnosis, a diagnostic dataset and benchmark with three contributions. First, a 25-method taxonomy groups methods into five mechanism families and links them to eight verified implementations and their valid diagnostic measurements. Second, for every supported method setting, we evaluate all sources in each fixed split against a per-source FullCache control before selecting FullCache-correct/compressed-wrong (C-to-W) rows separately for each method-setting, so no compressor defines another's test set. Third, a common record format links paired outputs and run metadata to cache, likelihood, attention, and decoding measurements with explicit applicability states. On Qwen3-8B, four evidence-aware workloads yield 59 800 supported compressed runs over 2600 sources and 12 520 C-to-W rows. Under fixed diagnostic rules, 63.2% have low or partial measured/projected coverage. Only 19 rows (0.2%) combine high measured/projected coverage with strong likelihood drift; another 2,126 (17.0%) preserve structural position addressability, for which representation fidelity remains unknown, while showing the same drift. Against C-to-C success controls, all ten diagnostics separate failed from successful compression (stratified AUROC 0.684-0.871). Among 96 reproducible low-EAR failures, a controlled 4x evidence-attention boost repairs 29.2%, versus 6.3% under a count-matched sham intervention and 3.3% degradation on matched C-to-C controls. Code and data are available at https://github.com/ChosenQC/KVDiagnosis.

### 1. 核心问题与研究动机

- **背景与痛点**：KV缓存压缩技术能够有效降低长上下文推理中的显存占用，是提升 LLM 长上下文推理效率的重要途径。然而，现有的评估方式存在显著盲区——任务级聚合分数（如平均准确率）只能反映整体正确率，既无法揭示哪些原本正确的执行在压缩后失败了，也无法解释失败发生的具体原因。
- **问题本质**：不同 KV 缓存压缩方法作用的对象完全不同（token 位置、层/头预算、通道、精度、语义块等），“保留50%”对不同方法而言可能意味着截然不同的资源压缩含义。相同分数的两种方法可能在不同样本上失败，而失败原因（证据被删除、保留表示损坏、访问机制失效、解码/评分偏差）需要完全不同的修复策略。
- **现有资源的不足**：已有的长上下文基准（LongBench、RULER、SCBench 等）仅提供任务级聚合结果；负样本基准和失败模式研究虽然注意到了个例失败，但均未同时提供完整逐源结果、FullCache 对照、方法各自的失败集和有效的诊断测量。没有公共资源能回答"哪个压缩器破坏了什么证据、为什么破坏、如何修复"这一诊断链条。

### 2. 方法论：核心思想与技术细节

**核心思想**：构建一个"诊断数据 + 评估协议 + 结构化记录"三位一体的基准。以 FullCache 为每个数据源的匹配对照，在每个方法-设置单元（cell）上独立选取 C→W（FullCache正确→压缩后错误）失败行，并附加仅在所测机制上有效的诊断指标，从而将"评估质量"与"失败归因"分离。

**关键技术细节**：

- **25 方法分类法（Taxonomy）**：将25种代表性KV缓存压缩方法归纳为五个机制家族：
  - Token eviction / position selection（token 驱逐/位置选择）：StreamingLLM、H2O、Scissorhands、TOVA、SnapKV、KeyDiff
  - Budget allocation / hierarchy（预算分配/层次结构）：PyramidKV、AdaKV、HeadKV、PolyKV
  - Query-aware access / channel pruning（查询感知访问/通道剪枝）：ThinK、Keyformer、Quest、Q-Filters、CHESS
  - Tensor / representation compression（张量/表示压缩）：QuantizedCache、KIVI、KVQuant、CommVQ、Palu、SALS
  - Chunk / semantic / learned state（块/语义/学习状态）：ChunkKV、DMC、KVzip、SCOPE
  - 其中8种方法经过适配器验证纳入实验评估（粗体标注），覆盖全部五个机制家族。

- **完整的配对运行矩阵**：每个数据源先执行一次 FullCache；所有受支持的（方法, 设置）单元均在该数据源上运行，使用相同的模型、提示词、分词器、解码器与评分器。仅在全部运行完成后，按单元独立提取 C→W 行，确保没有任何压缩器定义另一个压缩器的测试集。

- **四个诊断测量维度**（均在明确的适用性状态（measured/projected/structural/N/A）下记录）：
  - **缓存保留（Cache retention）**：ERR（evidence retention rate，证据保留率）与 ECov（evidence coverage，证据覆盖率），按层-头槽（layer-head slot）平均以避免跨头并集造成虚假完美覆盖。
  - **预测分布（Predictive distribution）**：ΔNLL（压缩与 FullCache 的 teacher-forced 负对数似然差）、GPR（几何概率比）、KL 散度、Top-50 重叠率、gold-token 秩位移。
  - **注意力访问（Attention access）**：EAM（证据注意力质量）、EAR（证据注意力保留率，压缩后与 FullCache 的比值）、NEAE（归一化证据注意力富集度）。
  - **解码与评分（Decoding/scoring）**：首/均值 gold 秩、解码停止原因、归一化输出等。

- **诊断分类规则**：六条预声明的互斥规则 + 冲突/模糊两个回退标签，将 C→W 行归类为低映射覆盖率、部分映射覆盖率、高覆盖漂移、结构位置漂移、低EAR候选、解码/评分候选等观测性签名。

- **重要公式**：
  - 压缩导致的失败率：r_CW = |F_d,m,b| / |{i∈X_d : correct_F_i = 1}|
  - ERR_z = (1/|U_z|) Σ_u |R_z,u ∩ E_i| / |E_i|
  - ECov_z = (1/|U_z|·J_i) Σ_u Σ_j 1[|R_z,u ∩ E_i,j|/|E_i,j| ≥ 0.5]
  - ΔNLL_z = NLL_C_z − NLL_F_d,i
  - EAR = 压缩后证据注意力质量 / FullCache 证据注意力质量

### 6. 主要结论与发现

- **失败频率（RQ1）**：聚合分数相近的方法可能拥有 2.5 倍的 C→W 率差异（如轻档下 TOVA/AdaKV/SnapKV/QuantizedCache 分数差 0.3 分，但失败率 0.8%–2.0%）。C→W 率随压缩强度增加在所有工作负载上一致升高（8/7/10/9% → 46/42/36/40%），但各方法的失败集合与任务分布高度特化（如 StreamingLLM 集中在检索类任务，ChunkKV 集中在多键检索和变量追踪）。
- **诊断分离（RQ2）**：全部10项诊断指标均可区分 C→W 与 C→C（分层 AUROC 0.684–0.871），其中 gold-rank shift（0.871）、KL（0.869）、ΔNLL（0.853）、Top-50 分歧（0.850）和 EAR loss（0.823）最强。63.2% 的失败行表现为低/部分证据覆盖率。仅0.2%（19行）兼具高覆盖与强似然漂移；ThinK/QuantizedCache 的2,126行（17.0%）保留结构位置可寻址性、表现相似漂移，但其表征保真度未知。96个可复现低 EAR 失败中，4倍证据注意力提升修复 29.2%，假干预仅修复 6.3%（McNemar p=2.98×10⁻⁶），C→C 安全对照仅退化 3.3%。
- **相似分数的隐藏差异（RQ3）**：SnapKV（84.8）与 TOVA（85.7）分数接近，但 12 个工作负载-设置单元中 11 个的失败集 Jaccard 低于0.38，说明相似聚合质量不意味着可互换的失败行为。
- **跨模型迁移（RQ4）**：覆盖率诊断在 Falcon3-7B 与 Mistral-24B 上高度相关（ρ=0.969/0.957），故障频率从 7.7%/2.1% 升到 29.5%/15.9%；但量化漂移（QuantizedCache、ThinK）呈现强模型特异性（Qwen 2b 失败的 ΔNLL 2.153 vs Falcon/Mistral 0.348/0.021），提示"可迁移的是诊断程序而非度量绝对值"。

### 7. 优点与亮点

- **方法新颖性**：首次将压缩失败的"诊断"与"评估"系统解耦，提出从缓存保留→预测分布→注意力访问→解码/评分的组件级签名框架，且每个签名附带明确的机制适用性约束。
- **设计严谨性**：FullCache 对照、完整运行矩阵、方法独立失败选择（避免彼此定义测试集）、明确的 N/A 语义（不支持/未定义/无效轨迹均单独记录而非丢弃）贯穿始终；C→C 对照组验证诊断指标的最小充分性。
- **干预验证**：不仅提供观测性诊断，还通过受控的注意力提升干预实验建立了低 EAR→修复的因果链，且同时包含 sham 对照和 C→C 安全对照，实验逻辑严密。
- **机制-诊断映射清晰**：附录详细记录了每个方法的转化对象和相应可用的测量类型（直接/投影/结构可寻址/N/A），避免跨机制的无意义比较。
- **代码与数据可复现**：版本化发布、自动化一致性校验、确定性单卡结果、明确的依赖清单和模型修订号；并公开了已被排除实现（PyramidKV）的完全重复性审计细节（内容相等）。

### 8. 不足与局限

- **模型覆盖**：主实验仅限 Qwen3-8B 单一模型；注意力诊断和干预实验仅限 Qwen，跨模型验证未覆盖注意力诊断。
- **方法覆盖**：25 方法分类法中的大部分方法未纳入评估（仅8种验证实现）；ThinK/25% 设置不受支持；PyramidKV 因适配器审计发现等于 SnapKV 而被排除。
- **QA 数据集的统计局限**：Qasper 和 HotpotQA 的 FullCache 正确来源较少（59/148），相应 C→W 行统计受小分母限制，且 QA 评分器为基准自定义（基于子串包含）而非官方评分。
- **解码策略单一**：仅使用贪婪解码，未评估采样、束搜索等对压缩失败模式的影响。
- **指标解释边界**：结构位置可寻址性不等于表征保真度（ThinK/QuantizedCache 的 ERR/ECov 为 N/A）；多数诊断均属观测性特征，不能单独确定因果链路；分层 AUROC 因数据源跨单元重复出现，置信区间仅具有描述性。
- **应用范围限制**：延迟、吞吐量、字节数与能耗明确超出范围；跨请求复用、分页、调度等系统级机制不在基准内；研究结论基于单确定性运行，未做多次随机化重复。
- **算力披露**：论文未提供总训练/推理算力消耗，影响成本可复现性评估。
