## 摘要
三元大语言模型使权重主导的投影变得紧凑高效，但注意力机制仍存在不匹配：其K/V缓存在线创建，且通常由独立的高精度引擎处理。单独压缩该缓存无法解决这一不匹配。为了使用与三元投影相同的查表机制执行注意力，在一次归约中累积的值必须保持兼容的表示和尺度。在因果解码过程中，这对键和值的要求也有所不同，因为新生成的值可能属于未完成的缓存块。本研究开发了一种面向三元大语言模型的统一查表推理方法。它将运行时K/V状态存储为按注意力归约结构组织的缩放多平面有符号数字。生成的数字平面直接由激活导出表使用，避免了缓存存储与注意力计算之间的密集K/V具体化。该设计结合了在线K/V形成、对不完整值块的有界处理，以及用于线性投影和注意力的共享多流数据路径。约束引导搜索为目标质量-效率权衡选择表示和执行策略。在原生和训练后三元模型上的实验验证了该方法在缓存容量、模型质量和硬件效率方面的有效性。

## Abstract
Ternary LLMs make their weight-dominated projections compact and efficient, but attention remains a mismatch: its K/V cache is created online and is typically processed by a separate higher-precision engine. Compressing this cache alone does not resolve the mismatch. To execute attention with the same lookup-table machinery as ternary projections, values accumulated in one reduction must retain a compatible representation and scale. This requirement also differs for keys and values during causal decoding, because newly generated values may belong to an unfinished cache block. This work develops a unified lookup-table inference approach for ternary LLMs. It stores runtime K/V states as scaled multi-plane signed digits organized around the reduction structure of attention. The resulting digit planes are consumed directly by activation-derived tables, avoiding dense K/V materialization between cache storage and attention computation. The design combines online K/V formation, bounded handling of incomplete value blocks, and a shared multi-stream datapath for Linear projections and attention. A constraint-guided search selects the representation and execution policy for a target quality--efficiency trade-off. Experiments on native and post-training ternary models validate the approach across cache capacity, model quality, and hardware efficiency.

## 一、论文的核心问题与整体含义

### 研究背景
- 大语言模型（LLM）在自回归推理中面临高成本和不断增长的K/V缓存问题
- 三元LLM（如BitNet b1.58、Spectra、Falcon-E）将线性层权重约束为 {−1, 0, +1}，显著减少权重存储
- 分组查表（LUT）执行天然适合三元线性投影：以"表构建 + 查表 + 归约"替代逐乘积乘法

### 核心矛盾
- **现有三元LLM加速器只对静态权重使用LUT**，注意力（QK⊤ 和 PV）仍由独立的整数或浮点数据路径处理（如TeLLMe、TENET、VitaLLM、LUT-LLM）
- 即使对K/V缓存做了量化压缩（如KIVI、KVQuant等），仍需**物化出中间浮点K/V**供注意力计算，无法直接用LUT消费
- 根本原因：参与一次LUT归约的值必须共享同一尺度，否则需要浮点缩放和累加。这对K和V的要求不同：
  - QK⊤ 中，每个K token产生一个完整的分数，允许token局部尺度
  - PV 中，输出值需要跨多个token累加V数据，token局部尺度不适用，需按值通道组织

### 研究目标
将**运行时动态K/V注意力**纳入与静态三元权重相同的LUT计算框架，实现线性层、QK⊤、PV的**统一LUT推理**。

## 二、论文提出的方法论

### 2.1 核心思想：有符号数字K/V表示

- **块级限制有符号数字（RSD）量化**：每个K/V块使用一个共享缩放因子 sb 和 R 个RSD平面（restricted signed-digit planes）
- 每个平面内是 {−1, 0, +1} 的三元数字，以G=3分组打包为5位LUT地址
- 平面位置由模板选择，通常为2的幂次位置：pb[r] = {0, Δ₁, Δ₁+Δ₂, ...}
- 静态三元权重是 R=1 的特殊情况，从而统一了权重与K/V的表示

### 2.2 关键公式

**LUT组地址映射**（G=3，27种状态）：
```
idx_G(a) = Σ (a_j + 1) · 3^(G−1−j)
```

**LUT表构建**：
```
T_g[idx_G(a)] = Σ X(g×G+j) · a_j
```

**统一LUT输出计算（含RSD K/V）**：
```
Y = Σ_b s_b · Σ_g T_g[idx_G(d_{g,r})] · Σ_r 2^{p_b[r]}
```

### 2.3 执行机制约束与解决

| 约束 | QK⊤ | PV |
|------|-----|-----|
| RHS列 = 缓存token | RHS列 = 值通道 | 归约维度 = 头维度 |
| K块token局部、生成即定稿 | V块跨token区间，因果解码时最新后缀不完整 | |

**V-tail 有界尾部机制**：
- 维护一个最多 BV 个token的未完成V区间（权威BF16值 + 两个打包RSD影子银行）
- 每次追加后重新计算共享尺度、重编码完整前缀进非活动影子银行
- 原子提交（长度+尺度）后才允许PV读取
- 尾部完整时直接提交为定稿块，总开销与上下文长度无关

### 2.4 硬件架构
- **DQEU（动态量化编码单元）**：在线编码K/V为RSD平面，含absmax/缩放路径、最近邻引擎、K/V压缩器
- **统一多流数据通路**：一个集群内L个PCU/LUT对、最多S_max个RHS流，线性层、QK⊤、PV共享同一数据流
- **双缓冲**：LUT表构建与执行重叠、DQEU量化与投影执行重叠
- **两种配置**：
  - A8：激活侧（A/Q/P）量化为INT8，DQEU同时编码A/Q/P与K/V
  - A16：激活保持BF16，DQEU仅编码K/V

### 2.5 联合设计空间探索（DSE）
- 四阶段多保真流：指定 → 联合搜索空间构建 → 候选生成/仿真/验证 → 部署
- 优化变量：块形状 B、各RHS组平面数 R_w ∈ {1,2,3}、指数间隙模板 Δ_b
- 使用线性规划松弛 + 贪心修复生成候选策略，仿真器评估部署成本（延迟、外部流量、全局缓冲区峰值），held-out NLL 约束筛选
- 关键洞察：Δ（指数间隙）在固定R下不影响执行周期但改变量化保真度，实现"零硬件成本"的精度调整

## 六、主要结论与发现

1. **表示统一可行**：将K/V编码为RSD平面后，注意力可以直接用与三元权重相同的LUT机制计算，无需重建稠密K/V
2. **质量保持**：固定R=3时，所有模型与稠密BF16 K/V相差不超过0.50 pp；混合R策略的精度损失可控（0.56–1.86 pp）
3. **硬件收益显著**：
   - 编码器面积开销极小（A8仅2.2%、A16仅3.9%），取代的稠密注意力阵列面积占比达64.5%（A8）/254.4%（A16）
   - A8配置下Falcon-E-3B的注意力吞吐/面积提高2.52×、吞吐/功耗提高2.30×
   - A16配置下OPT-350M分别提高4.78×和8.61×
4. **K/V压缩率高**：打包K/V负载仅为BF16的21–23%（含元数据开销）
5. **DSE有效**：代理与实测NLL的Spearman相关性达到0.998；质量门控制操作点，紧化ϵ=0.01时选择较保守策略，放宽ϵ=0.08时选择更快策略
6. **记忆体流量节省**：BITNet-2B达40.5%，OPT-2.7B达57.3%（最大设置下）
7. **请求级收益**：4K上下文下TTFT提升1.75–1.81×，平均TPOT提升1.80–1.92×

## 七、方法优点

1. **统一表示是核心突破**：首次将动态K/V纳入与静态三元权重相同的LUT执行框架，消除了异构计算路径
2. **量化感知K/V布局**：针对QK⊤和PV的不同归约结构设计了不同的布局方案，这是此前工作未深入处理的
3. **V-tail有界处理**：以有界缓冲区和原子提交机制解决因果解码中V块"未完成前缀"问题，开销与上下文无关
4. **Δ模板的"零成本"精度调优**：在固定平面数下利用指数间隙调整适应块分布，不增加执行周期和硬件
5. **形式化DSE方法**：线性规划松弛 + 贪心修复 + 多保真验证，有效缩小搜索空间
6. **实验设计严谨**：吞吐匹配基线正确分离架构收益与精度收益；门级功耗分析保证功耗报告的可信度
