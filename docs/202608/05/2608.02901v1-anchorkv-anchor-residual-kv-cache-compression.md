## 摘要
键值（KV）缓存是长上下文大语言模型推理中主要的内存瓶颈。现有方法从两个相反的方向解决这一问题：驱逐方法会永久丢弃token，一旦被丢弃的token后来被证明是关键信息，就会降低性能；而量化方法虽以低精度保留所有token，但压缩能力有限。我们提出AnchorKV，一种压缩方案，在不丢弃任何token的情况下将缓存缩小20倍。AnchorKV使用一组精确存储的锚点来表示缓存，通过每个token最相似的锚点来表达所有其他token，并且只优化那些近似值对模型输出影响最大的token。AnchorKV在多个模型和数据集上持续保持准确性，在70B规模下保留了全缓存得分的99%，同时以一小部分成本保留整个上下文。

## Abstract
The key-value (KV) cache is the primary memory bottleneck in long-context LLM inference. Existing approaches attack it from opposite ends: eviction methods permanently discard tokens, degrading performance whenever a discarded token later proves essential, while quantization methods retain all tokens at low precision but offer limited compression. We propose AnchorKV, a compression scheme that shrinks the cache by $20\times$ without discarding a single token. AnchorKV represents the cache using a small set of anchors stored exactly, expresses every other token through its most similar anchor, and refines only those whose approximation most affects the model's output. AnchorKV consistently preserves accuracy across models and datasets, retaining 99% of the full-cache score at the 70B scale, while keeping the entire context at a fraction of its cost.

## 一、核心问题与整体含义（研究动机与背景）

- KV缓存是长上下文LLM推理中的主要内存瓶颈：每个token每层都要存储一个键和一个值，缓存随上下文长度和批次大小线性增长，且每个解码步骤都要完整读取。例如，128K上下文的Llama-3.1-8B，仅bf16 KV缓存就需16 GiB，与模型权重相当。
- 现有压缩方法各有缺陷：
  - **驱逐（Eviction）方法**（如SnapKV、PyramidKV、AdaKV）：永久丢弃 token，压缩率高，但评分发生在查询已知之前，被丢弃的 token 若后续被需要则无法恢复，导致性能严重下降。
  - **量化（Quantization）方法**（如TurboQuant）：保留所有 token，但受限于位宽，精度随压缩率快速下降，压缩率通常被限制在约5×以内。
  - **离线和检索方法**：虽能恢复被驱逐状态，但需要额外传输和调度，将内存问题转化为传输问题。
- AnchorKV 旨在同时实现**高压缩率**与**全上下文可及性**：不丢弃任何 token，通过锚点-残差表示将缓存压缩20倍，同时保持接近完整缓存的精度。

## 二、方法论：核心思想、关键技术细节与算法流程

### 1. 核心思想
- 在每个 KV 头中，选择少量 **锚点（anchors）** 并精确存储它们的键值向量。
- 每个非锚点 token 由其最相似的锚点方向上的投影来近似，仅存储一个锚点索引和一个标量系数。
- 对近似误差最影响注意力输出的 token，额外存储量化残差。
- 整个压缩过程在 prefill 结束时一次性完成，不改变注意力计算，用户只需设置一个参数：保留缓存比例 θ。

### 2. 锚点-残差表示
- 对每个非锚点向量，选择最相似的锚点：
  \[
  a(i) = \arg\max_{a\in A} \frac{|\langle x_i, x_a\rangle|}{\|x_i\|\|x_a\|}
  \]
- 投影系数与残差：
  \[
  \gamma_i = \frac{\langle x_i, x_{a(i)}\rangle}{\|x_{a(i)}\|^2},\quad \tilde{x}_i = \gamma_i x_{a(i)},\quad r_i = x_i - \tilde{x}_i
  \]
- 重建公式：\(\hat{x}_i = \tilde{x}_i + \mathbf{1}[i\in R]\tilde{r}_i\)。
- 键和值独立处理，但共享锚点位置，各用各的投影系数与残差集合。

### 3. 锚点选择
- 最后 W 个位置始终精确存储（即“最近窗口”），并作为观察查询。
- 其余锚点按 SnapKV 式注意力分数选择（占 ρ 比例），其余部分从上下文随机采样，以改善锚点方向覆盖。
- 键的投影在 RoPE 之前完成，因为位置旋转会降低方向相似性；解码时再旋转。

### 4. 残差的分配：注意力输出感知评分
- 基于一阶泰勒展开，将输出误差分解为键通道和值通道：
  \[
  \Delta y \approx \sum_t \alpha_t(\Delta s_t - \Delta s)(V_t - y) + \sum_t \alpha_t \Delta V_t
  \]
- 对每个 token 计算键与值的效用分数（利用观察窗口的查询），效用越高，越优先分配残差：
  \[
  u^K_t = \frac{1}{m}\sum_{w=1}^m (\alpha_t^{(w)})^2 \frac{(q^{(w)\top}R_t r^K_t)^2}{D}\|V_t - y^{(w)}\|^2, \quad u^V_t = \frac{1}{m}\sum_{w=1}^m (\alpha_t^{(w)})^2\|r^V_t\|^2
  \]
- 残差预算在层内所有 KV 头之间**池化分配**（按效用排序），各头可获得的预算不均等。

### 5. 残差量化
- 残差经随机 Hadamard 旋转后，按每 token absmax 缩放，用 2-bit Lloyd-Max 码本量化，每个码 4 个打包成 1 字节。
- 每个存储残差需 D/4 字节坐标 + 1 个 scale。

### 6. 字节预算与存储计划
- 给定保留比例 θ，锚点和元数据先扣除，剩余字节数用于购买残差数 N：
  \[
  N = \max\left(0, \left\lfloor \frac{\theta M_{\text{full}} - M_{\text{base}}}{b_{\text{res}}} \right\rfloor\right)
  \]
- 键和值各分一半残差名额。
- 压缩后的缓存直接用于解码，使用类似 FlashAttention 的 tiled kernel 按块重建，不物化稠密缓存。

## 六、主要结论与发现

- AnchorKV 在 20× 压缩率下的得分**高于所有驱逐基线在 10× 时的得分**，即同等精度下内存减半。
- 在 Llama-3.1-70B 上，20× 时 RULER 得分保留率达 99.3%（94.4 vs 95.0），远高于最强基线的 86.8%。
- 随着模型规模增大，AnchorKV 的保留率提升（8B: 93.5% → 24B: 95.3% → 70B: 99.3%），即在缓存最昂贵的场景下表现最优。
- 在 RULER 逐任务分析中，AnchorKV 的最低任务得分从未低于 FullKV 的 60%，而最强驱逐基线在多个任务上低于 16%，尤其在最需要全上下文聚合与抗干扰检索的任务上差距巨大。
- Needle-in-a-Haystack 中，AnchorKV 在 5× 下平均 0.94（FullKV 0.99），而最佳驱逐基线 AdaKV 仅 0.18，几乎全面崩溃。
- 消融证明：残差效用排序、跨头池化、随机锚点采样、Hadamard 旋转 + Lloyd-Max 码本、pre-RoPE 投影等均对精度有贡献，且预算越紧贡献越大。
- 效率上：decode 峰值内存减少约 19×，64K 以上延迟与 FullKV 持平甚至更快，批量场景下吞吐提升 1.26×，并发容量约翻倍。

## 七、优点

1. **全上下文保留**：不丢弃任何 token，从根本上避免驱逐方法“错杀”关键 token 的问题，保证了软注意力覆盖完整上下文。
2. **高压缩率与高精度的结合**：20× 同时保持 99% 以上精度（70B），远超量化方法的压缩上限。
3. **理论保证**：给出了输出误差界（定理），区分键误差的最坏情况与值误差的注意力加权均值，为方法提供理论依据。
4. **残差分配目标明确**：以注意力输出的一阶误差为准则，而非简单的注意力分数或残差范数，消融实验表明该方法最优。
5. **零训练、零调参**：压缩在 prefill 后一次性完成，与模型无关，用户只需设置一个 θ 参数。
6. **工程实现完整**：FlashAttention 风格的 tiled kernel 直接解码压缩表示，不重建稠密缓存，实际内存与延迟收益显著。
7. **实验设计公平**：所有方法在相同字节预算下比较，AnchorKV 固定配置，且包含多尺度模型、多类基准、逐任务分析、消融和效率评估。

8. **实际部署中的潜在问题**：稀疏残差存储和按需重建带来额外的访存与索引复杂度，文中虽报告了 Triton 实现的性能，但未与其他优化推理框架（如 vLLM、TensorRT-LLM）集成验证。
