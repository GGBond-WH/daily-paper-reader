## 摘要
在长上下文大语言模型推理中，键值（KV）缓存已成为主要的显存和带宽瓶颈，使得超低位量化变得越来越重要。然而，现有的基于旋转的INT2方法在完整的注意力读出之前就优化缓存统计量或代理误差，而模型最终却受经由注意力和输出投影$W_O$传播的误差影响。为了解决这一失配问题，我们提出了OptR，一种输出感知的旋转方法，用于最小化$W_O$后的注意力输出误差。OptR将$W_O$后的注意力输出误差分解为键诱导项和值诱导项，并通过完整的INT2量化和注意力路径学习逐头的正交校正。OptR进一步应用一种注意力等价的键重参数化，在不改变softmax分布的情况下减少大的逐通道偏移。在三种模型和五个推理与编码基准上，OptR持续改进了QuaRot和OSCAR，并增强了长上下文检索，同时保留了分页KV缓存格式，推理开销可忽略不计。

## Abstract
The key-value (KV) cache has become a major memory and bandwidth bottleneck in long-context large language model inference, making ultra-low-bit quantization increasingly important. However, existing rotation-based INT2 methods optimize cache statistics or proxy errors before the complete attention readout, even though the model is ultimately affected by the error propagated through attention and the output projection $W_O$. To address this mismatch, we propose \textit{OptR}, an output-aware rotation method that minimizes post-$W_O$ attention-output error. OptR decomposes the post-$W_O$ attention-output error into key- and value-induced terms and learns per-head orthogonal corrections through the full INT2 quantization and attention path. OptR further applies an attention-equivalent key reparameterization to reduce large channel-wise offsets without changing the softmax distribution. Across three models and five reasoning and coding benchmarks, OptR consistently improves both QuaRot and OSCAR and strengthens long-context retrieval, while preserving the paged KV-cache format with negligible inference overhead.

## 1. 核心问题与整体含义（研究动机和背景）

- **KV缓存瓶颈**：随着LLM模型增大和上下文长度增长，KV缓存在长上下文推理中成为显存和带宽的主要瓶颈。自回归解码时，每层需存储并反复读取所有历史token的键和值，显存与带宽消耗随上下文长度、批大小和模型深度增长。
- **INT2量化的必要性**：INT2仅需BF16 KV缓存1/8的存储、INT4的1/2，能在同等显存预算下支持更长上下文或更大批次。
- **INT2量化面临的困难**：量化组内所有值共享一个缩放因子，少数大离群值会扩大仅4个INT2级别所能表示的范围，导致大多数值的舍入误差增大，激进裁剪又会对离群值自身引入大误差。
- **旋转方法的优势与不足**：旋转方法通过正交矩阵将极端通道值分散到各维度上，使缓存更易于量化，且不改变张量形状和缓存布局，兼容分页KV缓存与融合解码内核。但现有方法（QuaRot、RotateKV、OSCAR）使用固定变换或基于缓存统计量、代理误差来选择旋转，**未直接度量最终传递到后续层的输出误差**。
- **论文的核心insight**：KV量化改变注意力读出，输出投影$W_O$将该变化映射到模型隐空间。能最好重建缓存键/值的旋转，不一定能最好保留$W_O$后的输出。因此论文提出**输出感知旋转（OptR）**，直接优化后$W_O$的输出误差，消除代理目标与实际损失之间的失配。

## 2. 方法论（核心思想、技术细节、公式/算法流程）

### 2.1 核心思想

OptR的出发点是：将INT2 KV量化视为输出空间优化问题，把$W_O$后的注意力输出误差分解为键诱导项和值诱导项，并通过完整INT2量化与注意力路径学习逐头的正交旋转校正。

### 2.2 输出误差分解

给定BF16注意力输出 $y^{\ell}_{t,j}$ 与量化后输出 $\tilde{y}^{\ell}_{t,j}$，误差可精确分解为：

$$\Delta y^{\ell}_{t,j} = \underbrace{\left(\sum_{s \le t}\Delta p^{\ell,j,h}_{t,s} v^{\ell}_{s,h}\right)(W^{\ell}_{O,j})^{\top}}_{\text{key-induced output error}} + \underbrace{\left(\sum_{s \le t}\tilde{p}^{\ell,j,h}_{t,s} \Delta v^{\ell}_{s,h}\right)(W^{\ell}_{O,j})^{\top}}_{\text{value-induced output error}}$$

- **键诱导误差**：键量化误差先扰动注意力logits，再经softmax和值加权后由$W_O$投影到输出空间（通过注意力分布间接影响）。
- **值诱导误差**：值量化误差经注意力加权聚合和$W_O$投影后的直接输出误差。
- 相比之下，重建式目标 $E_{rec} = \|K - \tilde{K}\|^2_F + \|V - \tilde{V}\|^2_F$ 只是代理，与模型实际观测到的 $E_{out} = \|\delta y_K + \delta y_V\|^2_2$ 可能偏向不同的旋转。

### 2.3 注意力等价的键重参数化

- 利用校准数据估计逐通道键均值 $\mu \in \mathbb{R}^d$，在旋转和量化前对键做中心化：$(k_s - \mu)R_K$。
- **注意力等价性**：从所有键中减去相同 $\mu$，对所有logits添加一个仅依赖查询的常数，不改变softmax分布。
- 为高效实现，将 $(k_s - \mu)R_K$ 改写为 $k_s R_K - \mu R_K$，离线预计算 $\mu R_K$ 后在旋转空间中做减法，避免额外内核。
- 仅对键做重参数化而不对值做，因为平移值会改变注意力输出。sink和recent token（保留BF16）也同样应用中心化。

### 2.4 逐头正交旋转校正（核心优化）

- 对每个KV头学习无约束矩阵 $A_K, A_V \in \mathbb{R}^{d \times d}$，构造反对称生成器 $S_K = A_K - A_K^{\top}$，$S_V = A_V - A_V^{\top}$。
- 校正后的旋转为：$R_K(A_K) = R^0_K \exp(S_K)$，$R_V(A_V) = R^0_V \exp(S_V)$。由于反对称矩阵的矩阵指数是正交的，故校正旋转始终正交。
- 可应用于任意初始化（QuaRot的Hadamard旋转或OSCAR的协方差旋转），无需修改目标函数。

### 2.5 输出感知的键校准

- 键旋转首先优化，此时值保持BF16以隔离键路径：
  - 目标函数 $L_K = \mathbb{E}_{(t,j)\in D}\left[D_{\text{KL}}(p_t \| p^K_t) + \lambda_K \frac{\|\mathbf{e}_K(t,j)\|^2_2}{d_{\text{model}}}\right]$
  - KL项保持注意力分布；第二项度量键诱导的$W_O$后输出误差。
- $\lambda_K$ 默认设为1.0。

### 2.6 输出感知的值校准

- 键旋转选定后，在量化键的注意力分布下优化值旋转：
  - $L_V = \mathbb{E}_{(t,j)\in D}\left[\frac{\|\mathbf{e}_V(t,j)\|^2_2}{d_{\text{model}}}\right]$
  - 直接度量值在注意力加权聚合和$W_O$投影后的输出误差，而非原始值重建误差。

### 2.7 INT2感知的正交校准

- 旋转生成器通过**完整INT2量化路径**优化：旋转 → 裁剪 → 分组 → INT2舍入 → 反量化 → 逆旋转。
- 由于INT2舍入不可微，使用直通估计器（STE）：$\partial Q_2(Z;c,G)/\partial Z \approx \mathbf{1}\{|Z| \le \tau_c\}$。
- 模型权重全程冻结，仅优化每头的旋转生成器；校准后旋转在推理时固定。

### 2.8 离线校准流程（Algorithm 1）

1. 从校准数据中估计每头键均值 $\mu_{\ell,h}$。
2. 初始化 $A_K, A_V \leftarrow 0$。
3. 循环T步（默认80步Adam，lr=0.02）：
   - 构造有效键（键重参数化 + 旋转INT2量化）→ 计算softmax分布 → 计算键诱导$W_O$后误差 → 更新$A_K$。
   - 固定键旋转，构造有效值（旋转INT2量化）→ 计算值诱导$W_O$后误差 → 更新$A_V$。
4. 返回各层各头的旋转 $\hat{R}_K, \hat{R}_V$ 与均值 $\mu$。

1. **离线校准依赖**：需要收集校准数据（GPQA解码轨迹），虽训练后一次性完成，但对没有代表性的校准分布的任务领域可能带来偏差。
2. **校准数据潜在泄漏**：校准与评估均源自GPQA-Diamond题池，虽分块不重叠，但存在同分布泄漏风险，结果的泛化性可能被轻微高估。
3. **硬件覆盖有限**：仅在A100 40GB上验证，未测试其他GPU（如H100、消费级）或推理引擎（如vLLM之外的实现）。
4. **TurboQuant对比不完整**：仅单次运行，统计噪声较大，公平性略有不足。
5. **模型覆盖有限**：仅3个模型，未覆盖更大规模（如70B+）或编码专用模型；对非推理类任务的泛化性未验证。
6. **λK依赖基线**：最佳λK值因基线旋转而异（QuaRot以λK=10最优，OSCAR以λK=1最优），虽然论文统一用λK=1避免基线特定调参，但说明超参数选择与初始化有一定耦合。
7. **长上下文上限**：64K/128K下性能虽有大幅提升但仍有明显下降（如Qwen3-8B 128K仅约41%），尚未完全弥合与BF16的差距。
