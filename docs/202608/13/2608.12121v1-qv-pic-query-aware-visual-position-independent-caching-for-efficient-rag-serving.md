## 摘要
检索增强生成（RAG）在多次查询中重复预填充相同的文本块，导致冗余计算。位置无关缓存（PIC）通过跨位置重用预计算的键值（KV）来缓解这一问题，但其效率受到大量文本标记的制约。将文本块渲染为图像可以将文本压缩为更少的视觉标记，但渲染图像的PIC比文本PIC面临更严重的质量下降。这种表示特定的差距主要源于独立编译的缓存之间的上下文不匹配，以及在视觉压缩过程中细粒度文本证据的丢失。现有的PIC修复方法主要通过选择性重计算来解决前者，但它们会产生在线计算，并且无法恢复丢失的文本细节。我们提出QV-PIC，一种由模型原生模板引导的面向查询的双分辨率PIC重用框架。在离线阶段，QV-PIC在模型原生聊天模板前缀下编译视觉缓存，无需在线重计算即可提高PIC质量。在线阶段，它以低分辨率保留全局上下文，并通过累积查询相关性分数在高分辨率预算内恢复细粒度的文本证据，从而保留视觉压缩的效率优势。在六项任务中，QV-PIC相比原始渲染图像PIC平均F1提升21.6个百分点，缩小了与原始文本PIC的差距，并比优化后的文本PIC高出2.58 F1，同时TTFT降低17.2%。相对于完整预填充，它减少了83.8%的TTFT。

## Abstract
Retrieval-Augmented Generation (RAG) repeatedly prefills identical text chunks across queries, incurring redundant computations. Position-Independent Caching (PIC) mitigates it by reusing precomputed Key-Value (KV) across positions, but its efficiency is constrained by the large volume of text tokens. Rendering text chunks as images can compress the text into fewer visual tokens, but the rendered-image PIC suffers more severe quality degradation than the text PIC. This representation-specific gap primarily arises from contextual mismatches across independently compiled caches and the loss of fine-grained textual evidence during visual compression. Existing PIC repair methods mainly address the former through selective recomputation, but they incur online computation and cannot recover lost textual details. We propose QV-PIC, a query-aware dual-resolution PIC reuse framework guided by model-native templates. Offline, QV-PIC compiles visual caches under the model's native chat-template prefix, improving PIC quality without online recomputation. Online, it preserves global context with low resolution and restores fine-grained textual evidence within a high-resolution budget by cumulative query relevance scores, retaining the efficiency benefit of visual compression. Across six tasks, QV-PIC improves average F1 by 21.6 points over vanilla rendered-image PIC, closes the gap to vanilla text PIC, and surpasses optimized text PIC by 2.58 F1 while reducing TTFT by 17.2\%. Relative to full prefill, it cuts TTFT by 83.8%.

# QV-PIC 论文详细中文总结

## 1. 核心问题与研究背景

- **RAG 服务中的冗余计算**：在长期文档 RAG 中，同一文本块会被不同查询反复预填充（prefill），产生大量冗余计算。传统前缀缓存要求请求共享固定前缀或结构，无法应对动态检索中文本块位置变化的情况。
- **位置无关缓存（PIC）的提出与局限**：PIC 通过预先独立编译文本块的 KV 缓存、在线按当前上下文顺序拼接，实现跨位置复用。但文本 PIC 的 KV 体积随上下文长度增长，仍面临较大的传输与计算开销。
- **视觉压缩的机会与挑战**：将文本块渲染为图像可用更少的视觉 token 承载更多信息，显著缩短可复用 KV 序列。然而实验表明，渲染图像 PIC 的质量下降远大于文本 PIC，原因有两方面：
  - **编译上下文不匹配**：独立编译的缓存缺乏完整预填充时存在的上下文条件，组合后出现缓存状态错位；
  - **细粒度文本证据丢失**：视觉编码将字符、数字、标点等压缩进少量视觉 token，关键答案证据可能被模糊、混淆或省略。
- **现有修复方案的不足**：既有 PIC 修复方法（如 EPIC、CacheBlend 等）主要靠在线选择性重计算处理上下文不匹配，但既引入额外在线计算开销，又无法恢复已被视觉编码丢失的文本细节。

## 2. 方法论：QV-PIC 框架

QV-PIC 采用离线与在线两阶段设计，核心是"模型原生模板引导 + 查询感知双分辨率分配"：

### 2.1 核心思想

- 离线阶段：在模型原生聊天模板前缀下编译视觉缓存，解决编译上下文不匹配问题，且不引入在线重计算。
- 在线阶段：低分辨率覆盖全局上下文以保证效率，通过累积查询相关性分数将有限的高分辨率预算分配给查询相关的渲染图像，恢复细粒度文本证据。

### 2.2 关键技术细节

**阶段一：模板条件化缓存准备（离线）**

- 对每个文本块 `c_i`，分别渲染低分辨率和高分辨率图像；
- 在模型原生聊天模板前缀 `h` 下独立编译 KV 缓存，随后剥离前缀 KV 仅保留渲染图像部分的 KV 条目：
  - `C_ri = Strip_h(KV_M([h; x_ri]))`（式 1）；
- 缓存库同时存放两种分辨率变体、token 数元数据、来源顺序元数据及源文本嵌入向量，供在线路由使用。

**阶段二：查询感知缓存组装（在线）**

- 使用冻结的 BGE-M3 编码器对查询和源文本分别嵌入并计算余弦相似度：
  - `e_i = E(c_i)/‖E(c_i)‖₂`，`e_q = E(q)/‖E(q)‖₂`（式 4）；
  - `s_i = max(e_qᵀ e_i, 0)`（式 5）；
- 按相关性降序排列，选择最小的排名靠前集合，其累积归一化正相关性达到阈值 α（默认 0.65），且数量不超过预算 B（默认 4）：
  - `k* = min(B, min{k : Σⱼ₌₁ᵏ s_πⱼ / Σᵢ₌₁ⁿ sᵢ ≥ α})`（式 6）；
- 选中的渲染图像使用高分辨率缓存，其余使用低分辨率缓存；
- 拼接时按当前上下文顺序排列，并对未旋转的 key 应用 M-RoPE 重锚定以匹配请求位置（式 2）；
- 在线仅需计算查询编码、相似度排序和查询后缀 prefill，无需渲染、视觉编码或全文 prefill。

### 2.3 在线成本

- 路由开销公式：`T_route = T_E(q) + O(nd) + O(n log n)`（式 9），其中嵌入查询占主导；
- 活跃前缀长度：`N(q) = Σᵢ n_ᵢ_L + Σᵢ∈S(q) (n_ᵢ_H − n_ᵢ_L)`（式 8），高分辨率开销仅支付给被提升的图像。

## 3. 实验设计

### 3.1 数据集

- 使用 LongBench 中六个长上下文问答任务，共 1,150 个样本：
  - **2WikiMQA**、**HotpotQA**、**MuSiQue**：多文档多跳证据聚合；
  - **MultiFieldQA-en**、**NarrativeQA**：长单文档内证据定位与整体理解；
  - **TriviaQA**：事实性问答。
- 任务覆盖单/多文档、局部/分布式证据、直接检索/多跳推理等维度。

### 3.2 对比方法与 baseline

- 主模型为 **Glyph 9B**；
- 跨模型泛化测试使用 **GLM-4.1V-9B-Thinking**（同源系列）和 **LLaVA-OneVision-2-8B-Instruct**（跨系列）；
- Baseline 包括：
  - 前缀无关编译（prefix-free）；
  - 虚拟前缀编译（dummy prefix，k = 2/4/8/16）；
  - 高效重计算方法 **EPIC-2/4**；
  - 模板条件化文本 PIC 与渲染图像 PIC；
  - 全预填充（full prefill）；
  - QV-PIC 无模板条件消融版本。

### 3.3 评估指标

- **F1**：官方 LongBench token 重叠 F1；
- **TTFT**：从请求到首个 token 输出的延迟，三次运行取平均；
- **token 规模**：比较不同 DPI 下的视觉 token 数量。

### 3.4 实验配置

- Q1（模板条件化有效性）：对比前缀无关、dummy prefix、EPIC、模板前缀，在 72/120 DPI 下进行；
- Q2（DPI 均匀缩放）：从 72 DPI 扩展到 168 DPI（24 DPI 间隔），NarrativeQA 仅测到 120 DPI；
- Q3（整体性能）：QV-PIC 对比文本 PIC、均匀 72/120 DPI 渲染图像 PIC、无模板 QV-PIC 消融；
- Q4（跨模型泛化）：在 GLM-4.1V 和 LLaVA-OneVision-2 上重复比较。

## 6. 主要结论与发现

- **模板条件化编译显著优于其他修复策略**：120 DPI 下将渲染图像 PIC 从 32.9 提升到 52.1 F1（+19.2），把原本与文本 PIC 的 12.0 分差距转化为 0.4 分优势；优于长度匹配的 dummy prefix 5.2 分，远胜 EPIC 重计算（约 33 F1）。
- **均匀 DPI 缩放收益有限且不稳定**：F1 随 DPI 增加非单调变化，但 TTFT 持续上升，说明无差别提高分辨率并非高效策略。
- **QV-PIC 综合性能最优**：
  - 相比原始渲染图像 PIC，平均 F1 提升 **21.6 分**；
  - 相比优化后的文本 PIC，F1 高 **2.58 分**、TTFT 低 **17.2%**；
  - 相比均匀 120-DPI 渲染图像 PIC，F1 更高且 TTFT 更低；
  - 相比完整预填充，在线 prefill 时间减少 **83.8%**；
  - 消融证实两组件互补：模板条件化提供可靠的 KV 基础，双分辨率分配补充查询相关细节，二者结合获得所有任务上的增益。
- **跨模型泛化有效**：GLM-4.1V 和 LLaVA-OneVision-2 上 QV-PIC 均取得优于或接近最佳配置的 F1，且 TTFT 明显更低。

## 7. 优点

- **问题定位精准**：清晰地拆解了渲染图像 PIC 的两个独立失效模式（上下文不匹配 vs. 细节证据丢失），并针对性地设计对应模块。
- **离线编译、在线零重计算**：模板条件化质量修复完全在离线完成，在线路径无需渲染/编码/重计算，保持低延迟。
- **查询感知预算分配**：用嵌入相似度累积选择高分辨率对象，公式简洁、可解释、有阈值和预算双重控制，兼顾质量与成本。
- **消融设计干净**：通过控制变量清晰分离各组件贡献，验证了两者的协同效应而非简单叠加。
- **跨模型验证**：在 Glyph（渲染文本专用）、同源 GLM-4.1V、跨系 LLaVA-OneVision-2 上均验证有效，提高了结论的可推广性。
- **效率增益显著**：TTFT 相对全预填充降低 83.8% 的同时平均 F1 还超过文本 PIC，说明"质量与效率兼得"。

## 8. 不足与局限

- **DPI 扫描不完整**：NarrativeQA 因计算预算只测到 120 DPI，未能观察到该任务在更高 DPI 下的趋势。
- **未与其他多模态缓存系统直接对比**：MPIC、VLCache 等仅在相关工作部分讨论，缺乏端到端实验比较，无法判定 QV-PIC 在同类方法中的相对位置。
- **真实部署开销被低估**：TTFT 测量未包含离线缓存存储、管理、网络传输及 GPU 显存占用等实际服务成本，仅反映在线计算延迟。
- **默认编码器偏差风险**：依赖 BGE-M3 的余弦相似度作为相关性信号，其对不同领域/语言文本的排序质量可能影响高分辨率分配效果，论文未讨论嵌入质量边界。
- **渲染协议单一**：固定画布、字体和行距，仅改变 DPI；未探索版面布局、字体类型、行列数等因素对 PIC 质量的影响。
- **模型覆盖有限**：仅 8–9B 规模 VLM，未测试更大模型（如 70B+）或纯 OCR 专用模型；跨模型实验中的增益幅度也存在明显差异，说明依赖底层能力。
- **未验证真实 RAG 流水线**：实验基于 LongBench 的模拟检索场景，未接入实际检索器、动态重排序、多轮对话等真实 RAG 服务环境，检索噪声对 PIC 组装质量的影响未知。
