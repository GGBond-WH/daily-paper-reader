## 摘要
键值（KV）缓存存储来自过去令牌的信息，是长上下文推理中主要的存储瓶颈。现有的量化方法通过以较低精度的数据类型统一表示KV缓存，并设计量化方案以最小化缓存本身的重构误差来解决此瓶颈，而没有考虑该误差如何通过注意力机制传播。我们证明，在白噪声量化模型下，期望的注意力感知失真可以分解为键和值的加性贡献，这些贡献在令牌和通道维度上分解。基于变换编码和逆注水（信号处理和率失真理论中的经典工具），我们引入了注意力感知变换编码（AATC），它通过在校准集上分配比特来最小化注意力感知失真。在Llama-3.1-8B-Instruct和Qwen-2.5-7B-Instruct上，在LongBench、RULER、GSM8K、MMLU-Pro和MATH-500上评估，我们的方法在约5.8倍压缩时实现了近乎无损的精度，而每个基线至少在某些设置下会降低性能。

## Abstract
The key-value (KV) cache stores information from past tokens and is a major memory bottleneck in long-context inference. Existing quantization methods address this bottleneck by representing the KV cache uniformly with lower-precision data types and designing quantization schemes to minimize reconstruction error in the cache itself, without accounting for how that error propagates through attention mechanisms. We prove that, under a white-noise quantization model, the expected attention-aware distortion decomposes into additive key and value contributions that factor across tokens and channels. Building on transform coding and reverse water-filling, which are classical tools from signal processing and rate-distortion theory, we introduce Attention-Aware Transform Coding (AATC), which allocates bits over a calibration set to minimize attention-aware distortion. On Llama-3.1-8B-Instruct and Qwen-2.5-7B-Instruct, evaluated across LongBench, RULER, GSM8K, MMLU-Pro, and MATH-500, our method achieves near-lossless accuracy at approximately $5.8\times$ compression, whereas each baseline degrades in at least some settings.

## 1. 论文核心问题与研究动机

- **背景问题**：KV 缓存（key-value cache）在长上下文大语言模型推理中存储全部历史令牌的键与值，是内存的首要瓶颈。随着上下文长度增长（可达百万级 token），KV 缓存线性增长，成为部署 transformer 模型时最主要的存储与延迟约束。
- **现有方法的局限**：已有的 KV 量化方法（如 KIVI、KVQuant）在设计量化方案时只最小化缓存本身的重构误差（MSE），属于"信号重建视角"；它们没有显式考虑"量化误差如何通过注意力机制传播到最终输出"。低秩方法（如 PALU）同样基于原始重构误差。
- **核心科学问题**：能否从率失真理论（rate-distortion theory）和变换编码（transform coding）出发，推导一个"注意力感知（attention-aware）"的失真度量，并据此设计比特分配方案，在固定比特预算下最小化*注意力输出的失真*，而非缓存自身的重构误差？
- **核心论点**：在白噪声量化模型假设下，注意力输出的期望失真可严格分解为键项与值项之和，二者在令牌维与通道维上完全因式分解。这一分解统一了此前看似独立的多种压缩手段（token 驱逐、量化、低秩投影），并为最优比特分配提供了理论依据。

## 2. 方法论

### 2.1 核心思想

将经典信号处理中的"变换编码"蓝图（先白化/去相关 → 再按分量强度分配比特）迁移到 KV 缓存压缩，但把失真度量从"缓存重构 MSE"替换为论文推导出的**注意力感知失真**。方法分为离线校准（确定变换与比特分配）与在线推理（执行量化与重构）两阶段，命名为 **AATC（Attention-Aware Transform Coding）**。

### 2.2 注意力感知失真分解（定理 1）

- **假设**：
  - 白噪声量化模型（Assumption 1）：键/值量化误差零均值、跨令牌与跨通道独立、键值间独立、奇次矩为零；
  - 键量化误差有界（Assumption 2）：|δk_ic| ≤ κσ_K。
- **定理 1（注意力输出失真的分解）**：对单步解码注意力 o = Σ aᵢ vᵢ W_O，量化后输出失真满足：
  - **D = D_K + D_V + R**，其中
  - 键项 **D_K = Σ_{i,c} aᵢ² ∥vᵢW_O − o∥² · q_c² · E[(δk_ic)²]**
    - 每项含义：aᵢ² 反映该 token 参与注意力的强度；∥vᵢW_O − o∥² 衡量该 token 相对注意力输出的"残差"（切换注意力到该 token 对输出的改变量）；q_c² 捕捉当前查询实际读取哪些键通道；
  - 值项 **D_V = Σ_{i,c} aᵢ² · E[(δv_ic)²] · ∥W_Oc∥²_F**
    - 即值通道误差被输出投影 W_O 的列范数按通道放大；
  - 余项 R 为高阶项，随量化噪声减小而消失（实验中在 2–4 bit 仍保持预测力）。
- **关键推论（因式分解）**：由于误差方差 E[(δk_ic)²] 只依赖比特分配、与令牌无关，D_K 与 D_V 各自分解为"令牌因子 × 通道因子"：
  - D_K = (Σᵢ aᵢ² ∥vᵢW_O − o∥²) · (Σ_c q_c² E[(δk_ic)²])；
  - 因此键与值可独立量化，通道级权值与令牌级权值互不耦合。

### 2.3 AATC 算法流程（Algorithm 1）

- **步骤一：白化特征去相关**（离线，针对权重矩阵 W_K、W_V）
  1. 以校准激活 X 计算经验协方差 Σ_X = (1/T)X⊤X，Cholesky 分解 Σ_X = LL⊤；
  2. 白化权重矩阵 W̃ = L⊤W，再对其做瘦 SVD：W̃ = U S P⊤；
  3. 将原投影分解为 W = A·B，其中 A = L^{-⊤}U√S，B = √S P⊤；
  4. 推理时缓存变换后的 H_K = X·A_K、H_V = X·A_V，恢复键值用 K = H_K·B_K、V = H_V·B_V，变换严格可逆（无损），全部损失限于量化步。
  - 注：该变换与 KVTC 的 PCA 变换在每层设置下等价（附录 D，命题 1），但 KVTC 用全局跨层变换且按重构误差分配比特，AATC 按层、按输出感知失真分配。
- **步骤二：注意力感知的逆向注水比特分配**
  - **键的水位分配问题**：
    - min Σ_{ℓ,c} w^(K)_{ℓ,c} (σ^(K)_{ℓ,c})² 2^{-2b_{ℓ,c}}，约束 Σb ≤ B_K；
    - 通道权重 w^(K)_{ℓ,c} = (1/T) Σᵢ ( (B^K_{ℓ,c})⊤ q^{(i,ℓ,c)} )²（即校准查询在变换后键通道上的投影能量）；
    - 连续松弛的闭式解为经典逆向注水：b*_{ℓ,c} = ½log₂(w_{ℓ,c}σ²_{ℓ,c}/λ)，当权重×方差低于水位 λ 时分配 0 bit（即隐式低秩截断）；
  - **值的分配**：目标与键类似，但通道权重换为 w^(V)_{ℓ,c} = ∥(B^V W_O)⊤_{ℓ,c}∥²_F（输出投影感知）；
  - 键与值分别设定独立预算 B_K、B_V；
  - 量化采用非对称统一标量量化，通道级缩放因子取自校准集 99% 分位数，令牌级缩放按每组计算。
- **最小化失真的分配**：全层联合、按通道混合精度，0–16 bit 范围；可自然地将低重要性通道分配 0 bit，等效于自适应秩削减（与固定秩 PALU 不同）。

## 3. 实验设计

- **模型**：Llama-3.1-8B-Instruct（8 个 KV 头、32 个查询头、32 层，AATC 用 G=2 头组）与 Qwen-2.5-7B-Instruct（4 个 KV 头、28 层，G=1 头组）。
- **基准（Benchmark）**：
  - **LongBench v1**：7 个英文子任务（单文档问答 TriviaQA/Qasper、摘要 QMSum/SAMSum、分类 TREC、代码补全 LCC/RepoBench-P）；
  - **RULER**：4k/8k/16k/32k 四种上下文长度的长文本检索与推理；
  - **GSM8K**：8-shot CoT 数学应用题；
  - **MMLU-Pro**：math 与 computer science 两个子类（5-shot 单选）；
  - **MATH-500**：0-shot CoT 数学竞赛题。
- **对比方法**：KIVI（通道级键量化和令牌级值量化，5.00×）、PALU（低秩投影 + 4bit 量化，5.39×）、KVQuant（非均匀量化 + 离群值处理，5.91×），以及作者自己的消融变体 **AATC var-only**（不做注意力感知加权、仅按方差分配，等价于每层版 KVTC 的重构误差准则）。
- **公平性设置**：所有方法统一保留前 4 个 token 与最近 128 token 窗口为全精度、窗口满后按 16/32 块刷新，保证压缩率可比。
- **校准数据**：变换使用 wikitext2；率失真分配使用 FineWeb + OpenR1-Math-220k 混合（各 128 条、共 256 条长度为 2048 的序列）。
