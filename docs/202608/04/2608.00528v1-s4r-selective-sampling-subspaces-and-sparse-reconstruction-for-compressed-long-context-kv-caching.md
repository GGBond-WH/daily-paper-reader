## 摘要
大型语言模型（LLM）中上下文窗口长度的增长显著增强了其长上下文能力，但由于键值（KV）缓存的存在，也带来了高昂的内存成本。尽管KV缓存的低秩压缩是一种有前景的解决方案，但现有方法面临两难困境：离线方法依赖外部校准数据，而在线方法则因全提示分解与重建而产生大量计算开销。在本文中，我们提出S$^4$R，它从选择性采样的标记中构建低秩子空间，并基于稀疏重建的KV表示计算注意力。S$^4$R使用提示感知初始化，从具有代表性的提示子集构建初始键/值基，从而在校准数据依赖性与预填充成本之间进行权衡。由于在每一步解码时完全重建缓存代价过高且损害吞吐量，我们进一步采用稀疏重建，仅在解码期间保留信息丰富的位置。在LongBench和RULER上使用Llama和Qwen模型系列的广泛实验表明，S$^4$R在近乎全缓存精度下实现了高达5倍的KV压缩，结合了固定压缩的效率与提示相关方法的适应性。

## Abstract
The growth of context window lengths in Large Language Models (LLMs) significantly enhances their long-context capabilities but incurs prohibitive memory costs due to the Key-Value (KV) cache. Although low-rank compression of KV cache is a promising remedy, existing methods face a dilemma: offline approaches depend on external calibration data, whereas online approaches incur substantial compute for full-prompt decomposition and reconstruction. In this paper, we propose S$^4$R, which builds low-rank subspaces from selectively sampled tokens and computes attention over a sparsely reconstructed KV representation. S$^4$R uses prompt-aware initialization to build initial key/value bases from a representative prompt subset, trading off calibration-data dependence against prefilling cost. Because fully reconstructing the cache at every decoding step is prohibitively expensive and hurts throughput, we further adopt sparse reconstruction to retain only informative positions during decoding. Extensive experiments on LongBench and RULER with Llama and Qwen model families show that S$^4$R achieves up to 5$\times$ KV compression with near full-cache accuracy, combining the efficiency of fixed compression with the adaptability of prompt-dependent methods.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：随着大语言模型（LLM）上下文窗口从128k扩展到数百万token，Key-Value（KV）缓存的内存开销急剧增长，甚至可能超过模型参数本身的内存占用，成为长上下文LLM推理部署的核心瓶颈。
- **核心问题**：低秩压缩是解决KV缓存内存问题的有效思路，但现有低秩方法面临两难困境：
  - **离线（固定）方法**（如Palu、LoRC、Eigen Attention）：依赖外部校准数据或预训练时分解投影矩阵，解码时效率高，但对校准数据敏感，在激进压缩比下精度下降明显。
  - **在线（提示相关）方法**（如ShadowKV、xKV）：推理时根据当前提示在线估计低秩表示，对当前上下文更鲁棒，但预填充阶段计算开销大（全提示SVD分解）。
- **论文核心洞察**：长提示的主导KV子空间既不需要外部校准集，也不需要处理整个提示——可以通过精心选择的**提示token子集**来近似。同时，KV缓存条目不应被均匀压缩或重建：sink token（注意力汇聚点）应全精度保留；大部分非sink token可存储在低秩系数空间，仅在可能对当前解码步骤重要时才重建。
- **研究意义**：S⁴R旨在弥补固定压缩与提示依赖方法之间的效率—适应性鸿沟，为大上下文KV缓存压缩提供一种新的实用路径。

### 2. 论文提出的方法论：核心思想、关键技术细节、公式与算法流程

S⁴R由两个阶段组成：**预填充阶段**与**解码阶段**。

#### 2.1 预填充阶段

**（1）Sink Token处理**
- 将前s个token（默认s=4）视为sink tokens，因其作为注意力全局枢轴，对维持长距依赖至关重要，**不做压缩**，其RoPE前的键（key）和值（value）表示以全精度存储。
- 其余token视为非sink tokens，进入低秩近似流程。

**（2）子空间构建**
- 对非sink tokens X∈R^{B×T×D}，采用**混合采样策略**选取子集X[I]（T′≪T）：
  - 早期位置的均匀采样；
  - 最近token的连续块（recent-to-uniform采样比例为7:3）。
- **Token-wise归一化**（关键步骤）：对采样token的key/value表示沿特征维度归一化，以减轻向量范数差异对SVD基的影响，使子空间更聚焦于方向信息而非幅度偏差。
- **截断SVD分解**（公式2）：对归一化后的采样表示进行秩r截断SVD：
  - U_{K/V}∈R^{B×T′×r}：左奇异向量
  - Σ_{K/V}∈R^{B×r×r}：奇异值
  - B_{K/V}∈R^{D′×r}：右奇异向量，充当低秩基
- **投影**（公式3）：将所有非sink token表示投影到学习到的子空间，获得系数表示 C_{K/V}=S_{K/V}B_{K/V}，其中 C_{K/V}∈R^{B×T×r}。

**（3）初始局部查询窗口**
- 将最近G个查询头、W个位置的查询投影到同一低秩子空间，用于解码阶段的高效相关性估计。

#### 2.2 解码阶段

**（1）压缩缓存更新**
- 每个新token先投影到低秩子空间获得系数：c_Q = s_Q B_K，c_K = s_K B_K，c_V = s_V B_V。
- key/value系数追加到缓存序列 C_{K/V,t} ∈ R^{B×(T+t)×r}。
- 查询系数保持固定大小滑动窗口（长度W，先进先出队列）。

**（2）潜在空间相关性估计**
- 在低秩系数空间中直接近似注意力分数：Z = C_Q(C_K)^⊤/√r。
- 应用因果掩码后再softmax归一化，得到每个缓存token的平均相关性得分 A_Q。
- 跨查询窗口和组（group）维度聚合（支持平均/最大池化），获得最终重要性得分。

**（3）稀疏重建与注意力**
- 选择重建位置 = **局部窗口**（最近W个token）+ **全局重要位置**（top-k，k=max(⌊ρL_t⌋−W, 0)）。
- 仅对选中的索引重建key/value：K̂ = C_K[Î](B_K)^⊤，V̂ = C_V[Î](B_V)^⊤。
- 重建的KV与全精度sink tokens拼接，按原始位置施加RoPE，然后执行标准注意力。

#### 2.3 内存分析

- 全缓存：M_full = 2(s+L_t)D′
- S⁴R持久缓存：M_S4R = 2sD′ + 2L_t r + GW r + 2D′r
- 内存比：M_S4R/M_full = (sD′+L_t r+½GWr+D′r)/((s+L_t)D′) → 当L_t≫s,r时趋近 r/D′。

### 6. 论文的主要结论与发现

1. **有效性**：S⁴R在LongBench上实现高达**5倍KV压缩**（20%内存），同时在Llama-3.2-1B和Qwen3-4B上取得最优平均分（对比低秩基线），在更大模型上保持竞争力。

4. **Sink token保留很重要**：全精度保留sink token在所有模型上带来一致的精度提升（最高+3.49分）。
5. **Token-wise归一化提升鲁棒性**：虽然对Llama-3.1-8B不是最优，但可防止高幅度KV状态主导SVD基，在Qwen2.5-14B上避免了大幅精度下降（53.19 vs 46.27）。
6. **采样子空间+S稀疏重建是可行路径**：结合固定压缩的低开销与提示依赖方法的上下文自适应性。
