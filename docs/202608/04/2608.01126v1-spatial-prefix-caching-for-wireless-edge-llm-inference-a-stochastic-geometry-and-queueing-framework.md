## 摘要
前缀缓存重用共享提示前缀的键值（KV）状态，可显著减少大型语言模型（LLM）推理的首 token 时间（TTFT）。然而，在无线边缘网络中，前缀状态分布在地理上分离的 GPU 节点上。邻近节点提供较短的无线电路径，但可能提供较少的重用；而较远的节点可能缓存更长的匹配前缀，但会带来额外的通信和排队延迟。此外，持久前缀与活动请求的 KV 状态竞争相同的 GPU 内存，因此激进缓存会降低推理并发性，并产生排队热点。本文针对这种空间通信-缓存-计算权衡，开发了一个随机几何与排队论框架。我们使用前缀森林表示提示工作负载，并定义一个祖先闭合的缓存配置，该配置可包含多个可重用前缀。边缘 GPU 节点形成泊松点过程，并独立地由缓存配置标记，从而产生解析可处理的空间层级。我们推导了在负载感知关联策略下的配置关联概率、条件服务距离分布、令牌级计算卸载比以及 TTFT 覆盖概率。不动点公式刻画了空间关联与多服务器 GPU 队列之间的耦合，而外部优化则在静态内存和稳定性约束下选择缓存配置分布。解析结果与蒙特卡洛结果高度一致。结果表明，延迟最优节点不一定是最邻近节点，且由于 GPU 内存耦合，TTFT 可能随缓存前缀深度呈非单调变化。

## Abstract
Prefix caching reuses the key--value (KV) states of shared prompt prefixes and can substantially reduce the time to first token (TTFT) of large language model (LLM) inference. In a wireless edge network, however, prefix states are distributed across geographically separated GPU nodes. A nearby node offers a short radio path but may provide little reuse, whereas a more distant node may cache a longer matching prefix but incur additional communication and queueing delay. Moreover, persistent prefixes and active-request KV states compete for the same GPU memory, so aggressive caching can reduce inference concurrency and create queueing hotspots. This paper develops a stochastic-geometry and queueing framework for this spatial communication--caching--computation tradeoff. We represent the prompt workload by a prefix forest and define an ancestor-closed cache profile that may contain multiple reusable prefixes. Edge GPU nodes form a Poisson point process and are independently marked by cache profile, yielding analytically tractable spatial tiers. We derive the profile-association probability, conditional serving-distance distribution, token-level computation-offloading ratio, and TTFT coverage probability under a load-aware association policy. A fixed-point formulation captures the coupling between spatial association and multi-server GPU queues, while an outer optimization selects the cache-profile distribution subject to static-memory and stability constraints. Analytical and Monte Carlo results agree closely. The results show that the latency-optimal node need not be the nearest node, that TTFT can be non-monotonic in cached-prefix depth because of GPU-memory coupling.

## 2. 方法论

### 核心思想
- **前缀森林与缓存配置**：
  - 用根树/森林 $T$ 表示所有可重用的提示词前缀，请求类型 $q$ 对应一条从根到叶的路径。
  - 缓存配置 $s$ 是“祖先闭合”的子集 $C_s$（若某节点被缓存，其所有祖先也必须被缓存），这可表示多个层级重叠的前缀。
  - 每个边缘节点独立选择一种配置 $s$，概率为 $\pi_s$；节点形成的泊松点过程（PPP）通过独立标记分解为多个 profile-specific 的 PPP（强度 $\lambda_s = \lambda_b \pi_s$）。
- **负载感知关联**：
  - 请求选择使预测 TTFT 最小的 profile：$J_{s,q}(r) = \xi r^\alpha + \bar{W}_s + T^{\text{pf}}_{s,q}$；
    其中 $\xi r^\alpha$ 是距离相关的通信延迟，$\bar{W}_s$ 是平均排队等待时间，$T^{\text{pf}}_{s,q}$ 是残余 prefill 时间。
  - 关联时使用平均排队延迟，性能分析时保留随机排队延迟分布。
- **排队模型**：
  - 每个 profile 节点看成一个 M/M/$c_s$ 队列，$c_s$ 是与缓存配置有关的并发度（由 GPU 内存和持久缓存占用决定）。
  - 通过 Erlang-C 公式得到等待概率、平均等待时间和等待时间分布。
  - 排队负载与关联概率相互依赖：关联概率决定各 tier 的到达率，到达率决定排队延迟，延迟影响关联，故使用阻尼不动点迭代求解。
- **TTFT 覆盖概率**：
  - 结合关联选择密度、服务距离分布和排队时间尾部，推导出 TTFT 覆盖概率（目标延迟内完成 prefill 的概率）。
  - 这是“LLM 推理中的无线覆盖概率”的概念对应，同时包含空间可用性、部分计算重传和队列可靠性。
- **放置优化**：
  - 外层优化问题选择 profile 概率分布 $\pi_s$，在平均内存预算、稳定性和可行并发约束下最大化 TTFT 覆盖概率。
  - 使用“投影同步扰动”算法（外优化）+ 不动点求解（内耦合）的嵌套流程。

### 关键技术细节
- **前缀森林价值定义**：对请求 $q$，配置 $s$ 提供的最长可重用前缀长度 $H_{s,q}$；原始 prefill 节省为 $g(L_q) - g(L_q - H_{s,q})$。
- **持久内存与并发度**：$B_s$ 是配置 $s$ 占用的持久内存；并发度 $c_s = \lfloor (M - B_s)/m_{\text{run}}\rfloor$，$M$ 是可用的 GPU 内存。
- **Erlang-C 排队公式**：利用 $\rho_s = \lambda_s'/(c_s \mu_s)$ 计算等待概率 $P^{\text{wait}}_s$，平均等待时间 $\bar{W}_s = P^{\text{wait}}_s / (c_s \mu_s - \lambda_s')$，等待时间 CDF 为尾指数分布。
- **不动点求解**：$\bar{W}^{(i+1)} = (1-\eta)\bar{W}^{(i)} + \eta Q(A(\bar{W}^{(i)}))$，其中 $A$ 是关联概率映射，$Q$ 是排队延迟映射，$\eta$ 为阻尼系数。

## 6. 主要结论与发现

1. **延迟最优节点不一定是最邻近节点**：因为更远的节点可能提供更长的可重用前缀，节省大量 prefill 时间，只要其预填充节约超过额外通信+排队开销。
2. **TTFT 随缓存深度非单调变化**：由于持久缓存占用 GPU 内存，导致并发度降低，排队增加；在轻负载下深缓存有利，而在重负载下浅缓存反而更好。
3. **队列感知路由器至关重要**：
   - 前缀敏感但忽视队列的路由在低负载下与负载感知策略接近；
   - 在高负载下，队列无关路由形成缓存热点，性能甚至低于最近邻路由。
4. **最优 profile 混合依赖负载**：高负载下应减少深缓存份额，扩大浅层/无缓存 fallback 以保持并发性。
5. **边缘节点密度与 profile 多样性互补**：增加密度只能缩短距离并降低每节点负载，但若没有合适的缓存配置，覆盖概率仍会饱和；需要联合规划密度和缓存放置。
6. **具有设计指导意义**：浅层公共前缀应广泛复制，深层专用前缀应选择性部署，并保留高并发 fallback 容量。

  - 假设精确前缀匹配、独立 profile 标记、容量无限（全局一个模型副本）、慢时空静态流量；
  - 使用 M/M/c 近似连续批处理，忽略 chunked prefill、decode/prefill 分离等真实 serving 机制；
  - 通信模型是最简化的距离函数式，未考虑实际无线信道衰落、带宽共享和干扰。
- **缺乏与真实系统的对比**：没有与 Preble、Mooncake 等实际分布式前缀缓存系统对比，也没有在真实硬件环境验证，部署级指导还停留在概念层面。
- **优化求解局限**：外层优化使用随机扰动，无法保证全局最优，且只给出必要条件（面积容量不等式）而非充分条件，对非常规工作负载可能失准。
- **隐私与安全问题未深入**：论文只提到可基于聚合哈希运行，但对缓存目录泄露、访问模式侧信道等未做量化分析。
- **非凸优化与可扩展性**：虽然算法支持中等规模 profile，但大量 profile 时外层搜索和固定点迭代的计算代价仍未充分分析。

总之，该论文在理论框架层面做出了重要贡献，但实验验证以“机制证明”为主，未覆盖真实部署场景，这是其最明显的局限。

---

## 9. 总体评价

这篇论文为无线边缘 LLM 前缀缓存提供了首个统一的空间随机几何+排队论分析框架，其核心贡献在于将“缓存内容”从独立文件提升为层级化前缀森林，并显式建模 GPU 内存竞争对并发性的影响。理论分析与模拟验证的一致性表明方法可靠，得到的关键定性结论（最近节点不优、TTFT 非单调、队列感知必要性）对于边缘 LLM 服务设计具有启发意义。但由于缺乏真实硬件/流量验证，其定量结果只能视为趋势指示，走向实际部署还需补充实测校准。
