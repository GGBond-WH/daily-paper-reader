## 摘要
当前KV缓存量化是通过离线基准测试平均值来验证的；部署的系统无法判断压缩是否正在损害它当前服务的请求。我们为其提供一个可证明健全的运行时计量器，一种“用于KV量化的DTrace”：精确注意力与压缩注意力之间的总变差的逐（层、头、步）上界。该计量器分为两层：一个确定性的带范数见证界，对任何保持缓存的黑盒量化器和任何查询都成立（自适应安全，最坏情况柯西-施瓦茨加RoPE带幺正性）；以及一个更紧的概率证书，用于受控的减法抖动INT8量化器，在显式的请求级失败预算下（针对非自适应查询陈述；核心定理在Lean 4中机器验证）。三个结果。可观测性：该计量器通过一个环境守卫的补丁进入SGLang，任何注册为一个张量函数的方案都在实时服务中进行测量。修复：计量器驱动的门控，在见证饱和处进行风险排序，在信息充分处进行认证，凭经验在基准规模上恢复了质量底线。例如，在困难的RULER任务上，原始转换FP8从22.8回升至79.7，与未压缩的差异通过配对检验被限制在[+0.0, +0.8]内。分析：激进的方案依靠跨层误差抵消而存活，而非每步保真度。在28层扫描中，没有单一层的污染单独造成损失（0/28），并且经过认证的INT8缓存在SGLang中以相同内存服务1.88倍的KV标记。

## Abstract
KV-cache quantization is validated today by offline benchmark averages; a deployed system cannot tell whether compression is damaging the request it is serving right now. We give it a provably sound runtime meter, a "DTrace for KV quantization": a per-(layer, head, step) upper bound on the total variation between exact and compressed attention. The meter has two tiers: a deterministic band-norm-witness bound, sound for any cache-preserving black-box quantizer and for any query (adaptive-safe, worst-case Cauchy-Schwarz plus RoPE band-unitarity), and a tighter probabilistic certificate for a controlled subtractively-dithered INT8 quantizer under an explicit request-level failure budget (stated for non-adaptive queries; core theorems machine-checked in Lean 4). Three results. Observability: the meter enters SGLang through an environment-guarded patch, and any scheme registered as one tensor function is measured in live serving. Repair: meter-driven gating, risk-ranked where the witness is saturated and certified where it is informative, empirically restores the quality floor at benchmark scale. For example, raw-cast FP8 improves from 22.8 back to 79.7 on hard RULER tasks, with the difference from uncompressed bounded at [+0.0, +0.8] by a paired test. Analysis: aggressive schemes survive on cross-layer error cancellation, not per-step fidelity. In a 28-layer sweep, no single layer's pollution alone loses anything (0/28), and the certified INT8 cache serves 1.88 times more KV tokens at the same memory in SGLang.

### 1. 核心问题与整体含义（研究动机与背景）

- **核心痛点**：现有的 KV 缓存压缩技术（token 驱逐 H2O/SnapKV、通道/频率剪枝 ThinK/RAP、低秩分解 Palu/KQ-SVD、量化 KIVI/KVQuant 等）全部是**开环（open-loop）**的——策略离线固定或依赖启发式，压缩对当前输入实际造成的误差既不可观测也不可控。
- **具体症状**：论文观察到，在 query-agnostic 协议下，SnapKV 在 RULER needle 任务上从 100 分暴跌至 1.1–65 分，而服务系统**不发出任何信号**。部署系统无法判断压缩是否正在损害它此刻服务的请求。
- **前人局限**：Runtime-Certified Quantized Attention [5] 虽首次提供了运行时证书，但其最坏情况界（TV ≤ tanh(max|ε|)，数据无关）过于保守——在实际阈值（τ ≤ 0.2）下授权零压缩，证书虽然成立但毫无用处。
- **本文主张**：一个可用的证书**必须数据依赖**。论文提出 WitCert——一个"KV 量化的 DTrace"：对每个（层、头、解码步）给出精确注意力与压缩注意力之间总变差（TV）的**可证明上界**，将压缩从开环赌博变成可观测、可门控的系统量。
- **整体含义**：量化安全不只是"离线基准高"，而是要有"此刻正在服务的请求是否受损"的运行时保障，并能据此自动修复（回退到精确缓存）。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 2.1 计量目标与理论框架

- 对固定（层、头、解码步），设 p 与 p̃ 分别为精确与压缩 key 上的 softmax 注意力分布，TV 定义为 ½Σ|pₜ − p̃ₜ|。
- 选择 TV 作为目标的原因：(1) 它是操作量——注意力质量移动的量，静默丢针本质上是 TV 事件；(2) 它线性传播到注意力输出：‖y−ŷ‖ ≤ 2·TV·max‖vₜ‖ + Σp̃ₜρᵥₜ。
- 由于 TV ≤ 1 恒成立，计量器统一报告为 min(1, ·) 的形式。

#### 2.2 一个看似合理但不健全的界及其反例

- 论文先展示了一个自然但不正确的界（公式 1），其直觉是"误差被注意力加权，边界分散小 ⇒ TV 小"，但这忽略了误差符号。
- **最小反例**：p̃ = (½, ½)，c = (0.1, 0.1)，ε = (0.1, −0.1)，真实 TV = 0.0498，而公式 (1) 给出 0.0064——相差 7.8 倍。
- 该错误界曾通过 32,256 次聚合平均检验，但逐查询检验立即暴露——方法论教训是**证书必须逐查询、对抗性验证，绝不能在聚合中验证**。

#### 2.3 健全替换定理（Theorem 1）

- 令 A = E_p̃[e^c]，若对所有 t 有 |εₜ| ≤ cₜ，则 **TV(p, p̃) ≤ ½(A² − 1)**。
- 证明路径：柯西-施瓦茨给出 1/A ≤ E_p̃[e^ε] ≤ A，从而 |pₜ/p̃ₜ − 1| ≤ Ae^{cₜ} − 1，取期望即得。
- 用 500,000 次对抗性试验（极端符号模式、尖峰/平坦分布、大 c）验证。

#### 2.4 双层计量器

**Tier A：通用确定性见证界（黑盒、保持缓存方案）**
- 见证（witness）：写缓存时计算残差 rₜ = k̂ₜ − kₜ，按 RoPE 频带分组存储各带欧氏范数 w_{t,b} = ‖r_{t,b}‖（B=16 带时 32 B/tok/head）。
- **Lemma 1（RoPE 带幺正性）**：RoPE 旋转按频率对分块对角、每带内正交，因此残差的带范数**对查询位置不变**——解决"查询未到而需要数据依赖界"的核心障碍。
- **Theorem 2（健全黑盒 logit 界）**：|εₜ| = |q·rₜ|/√d ≤ (1/√d)·Σ_b‖q_b‖w_{t,b}，对任意查询和任意缓存保持方案成立。
- 该界是**自适应安全**的（最坏情况不等式），但成本是每 token 额外存储和计算。

**Tier B：受控量化器的亚高斯概率证书**
- 使用**减法抖动（subtractive dither）**量化：x̂ = s(round(x/s + ξ) − ξ)，ξ ~ U[−½, ½)，读时确定性重建。
- **Lemma 2**：均匀分布是亚高斯的，代理方差恰为 s²/12；logit 误差方差代理为 ς²ₜ = (1/d)Σ_c q²_c s²_{c,t}/12。
- 通过联合界得到：以 ≥ 1 − δ_loc 概率对所有 S 个 token 有 |εₜ| ≤ uₜ := √(2ς²ₜ log(2S/δ_loc))，再经 Theorem 1 传播。
- **请求级预算**：δ_loc = δ_req/(L·H·T)，按层、头、步联合分配。
- **关键范围声明**：概率保证仅对**非自适应查询**成立（预填充、教师强制、固定 token 轨迹）；自由解码中查询是之前压缩残差的函数，存在自适应依赖。Tier A 对此安全。
- **离群 RoPE 对**：每块按尺度能量选少量频对以 FP16 保留并排除在方差项外（m=4 时 16 B/tok/head），是覆盖率的头号杠杆。
- **不需要见证存储**——Tier B 只存载荷和尺度。

**两面对称界（Proposition 1）**：TV ≤ ½(A/A⁻ − A⁻/A)，对大激活单峰场景线性增长优于二次的 e 形式；但实测在真实激活上不产生收益（1.7× 更松），论文如实报告该负面结果。

#### 2.5 系统实现

- **写入路径**：任意方案的残差留见证；Tier B 只存 INT8 载荷 + 尺度 + 插槽键控的 Philox 抖动。
- **解码内核**：一个融合数据通道计算输出 y 和计量器累加 A = Σp̃ₜe^{uₜ}，跨 KV 分割用 LSE 权重合并（因为 A 和注意力输出同为 p̃ 的线性泛函）。
- **门控**：计量器超阈值则从 CPU 精确备份按块页面调入、重算、写回、见证归零；块级页面调入比整头回退降低 128 倍流量。
- **SGLang 集成**：环境变量守卫补丁（327 行），关闭时与上游逐位一致；打包的认证缓存（INT8 + 尺度 + 索引 + FP16 离群）在 SGLang 中获得 1.88× KV 容量。
