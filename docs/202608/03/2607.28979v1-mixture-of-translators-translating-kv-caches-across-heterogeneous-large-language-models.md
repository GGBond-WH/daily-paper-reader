## 摘要
异构大语言模型（LLM）系统日益依赖共享上下文、检索证据和多智能体对话历史，然而其内部的键值（KV）缓存仍然特定于模型，无法跨架构重用。因此，每个模型必须为相同上下文重复预填充或存储缓存，这限制了多模型推理和长上下文生成的可扩展性。我们提出混合翻译器（MoT），一种缓存翻译框架，将上下文KV缓存从源LLM映射到目标LLM的缓存空间。与依赖单一投影路径或全局共享潜在空间的先前方法不同，MoT使用多个翻译器模块来捕获多样化的源-目标映射。为了进一步减少残余翻译误差，我们引入了上下文校正损失，将重放的目标轨迹与原生目标轨迹对齐。我们揭示了缓存翻译中两种相互竞争的失败模式：早期注入导致的传播翻译偏移和晚期注入导致的最后状态偏移。MoT通过翻译器混合和目标侧校正来解决这些问题。在Qwen2.5、GPT-2和OPT模型之间的同质和异构翻译中，MoT保持了下游QA性能，包括Qwen2.5-7B规模的翻译，平均闭集QA准确率为51.0%，平均抽取式QA F1为0.43。在实际案例研究中，MoT为多智能体推理实现了保质量的内存重用，并在长上下文缓存增强生成中保留了直接上下文质量的96.3%，展示了跨异构LLM的可扩展KV缓存重用。

## Abstract
Heterogeneous Large Language Model (LLM) systems increasingly rely on shared contexts, retrieved evidence, and multi-agent dialogue histories, yet their internal key-value (KV) caches remain model-specific and cannot be reused across architectures. Consequently, each model must repeatedly prefill or store caches for the same context, limiting the scalability of multi-model reasoning and long-context generation. We propose Mixture-of-Translators(MoT), a cache translation framework that maps context KV caches from a source LLM into the cache space of a target LLM. Unlike prior approaches that depend on a single projection path or global shared latent space, MoT uses multiple translator modules to capture diverse source--target mappings. To further reduce residual translation error, we introduce a Context Correction Loss that aligns the replayed target trajectory with the native target trajectory. We reveal two competing failure modes in cache translation: propagated translation shift from early injection and last-state shift from late injection. MoT addresses them through translator mixtures and target-side correction. Across homogeneous and heterogeneous translations among Qwen2.5, GPT-2, and OPT models, MoT preserves downstream QA performance, including Qwen2.5-7B-scale translation with 51.0% average closed-set QA accuracy and 0.43 average extractive QA F1. In practical case studies, MoT enables quality-preserving memory reuse for multi-agent reasoning and retains 96.3% of direct-context quality in long-context cache-augmented generation, demonstrating scalable KV cache reuse across heterogeneous LLMs.

## 1. 核心问题与研究动机

- **问题背景**：异构大语言模型（LLM）系统（如多智能体协作、检索增强生成、长上下文缓存增强生成）日益依赖共享上下文、检索证据和对话历史，但每个模型的 KV 缓存是**模型特定的内部表示**，无法跨架构直接复用。结果导致同一上下文必须在每个模型中重复预填充或重复存储，造成大量计算和内存冗余。
- **核心矛盾**：现有缓存复用机制（如 Prompt Caching、CAG、TurboRAG）大多局限于同一模型或同一缓存格式；跨模型通信方法（如 C2C、Interlat、KVComm、LSC）要么依赖单一投影路径、要么假设架构兼容、要么依赖全局共享潜在空间，难以应对源/目标模型在深度、隐藏维度、注意力布局、KV 头结构等方面的异构性。
- **研究目标**：提出一种能将源模型上下文 KV 缓存"翻译"为目标模型缓存空间的框架，实现跨异构 LLM 的缓存复用，同时保证下游生成质量。

## 2. 方法论

### 2.1 核心思想

- 提出 **MoT（Mixture-of-Translators，混合翻译器）**：用**多个翻译器模块**将源模型上下文 KV 缓存映射到目标模型缓存空间，替代单一通用翻译器。
- 揭示缓存翻译中的**两种竞争性错误**：
  - **传播翻译偏移（propagated translation shift）**：翻译层位置过低时，早期注入的误差经残差网络逐层传播放大（虽然理论上界随层数指数衰减，但初始误差过大）。理论界为 ∥sL∥ ≤ (1+δ)^(L−TStart) ∥sTStart∥。
  - **末态偏移/校正赤字错误（last-state shift / correction-deficit error）**：翻译层位置过高时，上层剩余层数不足，无法充分校正翻译引入的偏移（校正赤字系数 dT:L 在最终层达到 1）。
- 两种错误随翻译窗口位置变化形成 **U 形损失曲线**，因此必须联合控制：min(∥sT∥, ∥sL∥)。

### 2.2 关键技术组件

1. **Mixture-of-Translators 架构**：
   - 多个骨干翻译器（基于交叉注意力的递归翻译模块，源自 LSC 但直接做 KV 到 KV 翻译，不引入共享潜在空间）。
   - **Token 级门控路由**：对每个 token 使用 Top-K 选择翻译器，并对选中的权重重新归一化：Tr_MoT(zu) = Σ_{m∈T_TopK(u)} g̃_m(zu) · Tr_m(zu)。
   - 理论保证（命题 3.2）：最优混合翻译器的翻译偏移不大于最优单翻译器。

2. **上下文校正损失（Context Correction Loss）**：
   - 将翻译后重放的目标轨迹与目标模型原生预填充轨迹对齐：L_CC = Σ_{ℓ=TStart+1}^{L} ‖ĥ^Tgt_ℓ − h^Tgt_ℓ‖²。
   - 实现中采用基于 KV 的启发式形式（比较重放与原生 KV 缓存），并证明在最终层 KV 投影满列秩条件下可降低末态偏移上界。

3. **完整流水线**（五阶段）：① 上下文预填充（源模型）→ ② KV 翻译（MoT 多翻译器）→ ③ 上下文重放（目标侧重建，含校正监督）→ ④ 提示预填充 → ⑤ 完成输出。
   - 通道映射采用**深度比映射（Depth-Ratio Mapping）**，从滑动窗口候选中选验证损失最小的通道集。
   - 重放阶段采用 **Top-S 源引导稀疏注意力**，用源模型注意力模式选取关键 token 位置，将重放成本从 O(N²) 降至近似线性。
   - 另提出 **MoT-h** 变体：翻译中间激活而非 KV 张量，由目标模型原生 K/V 投影恢复 KV 缓存，降低约一半内存/传输开销，但精度略有损失。

- **应用落地**：多智能体推理和长上下文 CAG 两个案例研究展示了"内存复用"与"存储复用"两条实际路径，且多智能体实验验证了缓存放逐策略（Free）的规模不变性。
- **工程变体**：MoT-h 提供内存效率优先的选项，体现方法可扩展性。

## 8. 不足与局限

- **校正赤字改善有限**：作者自认 MoT 主要靠降低 ∥sT∥ 和正交偏移 β 来减小 ∥sL∥，校正赤字系数 dT:L 变化甚微，需要能显式提升目标模型内在校正能力的目标或架构。
- **通道映射依赖深度比假设**：源/目标模型在指令微调、训练分布或表征组织差异较大时，深度比映射可能失效（论文仅在初步分析中给出一个反例，未系统解决自适应通道映射问题）。
- **未解决跨分词器翻译**：源与目标模型使用不同 tokenizer 时缓存位置无法对应，token 级翻译困难，限制了更广泛的异构系统。
- **模型规模覆盖有限**：最大模型为 7B（Qwen2.5-7B 仅作源模型），未验证更大规模（如 70B+）下的可行性与开销；小模型（OPT 系列）上 F1 绝对值很低，泛化性存疑。
- **额外开销**：MoT 引入多翻译器和重放阶段，峰值内存和 TTF T 明显高于 Native 和简单基线（如 2-agent 时仅 MoT 在约 3.3GiB 以上），论文将其描述为"边际成本"，但在资源受限场景中可能不可忽视。
- **公平性风险**：C2C-Project 与 LSC 为自行实现，缺少第三方代码交叉验证；KVComm 仅在同构设置中评估；此外论文为预印本，部分基准和基线代码链接的长期可用性未知。
- **训练数据与许可**：OpenWebText 底层网页文档来源异构；部分实验使用受 OPT 许可限制的模型，商业应用受限。
