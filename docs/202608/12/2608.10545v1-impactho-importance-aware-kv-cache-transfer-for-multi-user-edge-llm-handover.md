## 摘要
边缘LLM必须在用户在边缘节点之间切换时保持推理连续性，这需要将键值（KV）缓存迁移到目标节点。然而，同时发生的切换会使回程链路饱和，从而无法在移动性所限定的传输窗口内完成全部缓存传输。我们不是将带宽视为所有缓存条目同等价值来分配，而是按重要性对每个用户的KV缓存进行排序，仅传输其中信息量最大的部分，将词元级稀疏性转化为通信节约。我们将该迁移问题建模为一个多用户回程分配问题，以最大化所有用户的平均准确率。每个用户的部分缓存准确率作为其效用函数：一个在RULER基准上、跨模型和上下文长度拟合$R^2>0.99$的Sigmoid函数。由于重要性排序使高价值条目优先，准确率曲线的凹区间几乎覆盖整个缓存。我们提出的分配器将服务用户保持在该区间内，使每个时隙的分配问题成为凸问题。最优解通过闭式加权注水解法得出，该解法推广了信息论注水算法，并支持在线调度。所提出的分配器在500ms传输窗口内达到超过93.7%的平均准确率，比全缓存上限低0.5个百分点以内，并达到全知上限的98.2%-99.5%。

## Abstract
Edge LLMs must preserve inference continuity when a user hands over between edge nodes, requiring key-value (KV) cache transfer to the target node. However, simultaneous handovers saturate the backhaul, preventing full cache delivery within the mobility-imposed transfer window. Rather than allocating bandwidth as if all cache entries were equally valuable, we order each user's KV cache by importance and transmit only its most informative fraction, turning token-level sparsity into communication savings. We cast the transfer as a multi-user backhaul allocation problem that maximizes average accuracy across users. Each user's partial-cache accuracy serves as its utility: a sigmoid that fits measurements on the RULER benchmark with $R^2>0.99$ across models and context lengths. Because importance ordering front-loads the high-value entries, the concave region of the accuracy curve spans nearly the entire cache. Our proposed allocator keeps served users within this region, making each per-slot allocation problem convex. The optimum is derived via a closed-form weighted water-filling solution that generalizes information-theoretic water-filling and enables online scheduling. The proposed allocator attains over 93.7% average accuracy in a 500ms transfer window, within 0.5pp of the full-cache ceiling, and reaches 98.2-99.5% of a clairvoyant upper bound.

## 1. 核心问题与整体含义

- **背景**：边缘计算将 LLM 推理部署到网络边缘以提供低时延 AI 服务。当移动用户在边缘节点之间切换时，目标节点必须重建用户上下文以维持推理连续性。
- **挑战**：完整 KV 缓存体积远超原始文本；多用户同时切换会迅速饱和回程链路，导致完整缓存无法在移动性限定的传输窗口（如 500ms）内送达。
- **核心问题**：如何将有限的回程带宽在多个并发切换用户之间分配，以最大化平均推理精度？
- **关键洞察**：KV 缓存中不同条目的重要性差异显著，部分缓存即可维持大部分精度。按重要性排序传输，将 token 级稀疏性转化为通信节约。
- **整体含义**：论文提出的 ImpactHO 框架通过重要性排序与加权 water-filling 分配，将边缘 LLM 切换从“全量迁移”转变为“尽力而为的部分迁移”，支持任意时间推理（anytime inference），为带宽受限下的多用户边缘 LLM 切换提供了高效、可在线调度的解决方案。

## 2. 方法论

- **核心思路**：在源节点为每个 KV 条目分配重要性分数并按降序排列；切换时目标节点按重要性顺序接收缓存前缀，并在传输窗口到期后使用已接收的部分缓存恢复推理。调度器在每个时隙将共享回程带宽分配给并发用户，以最大化平均精度。
- **重要性排序**：采用 Fast KVzip 的门控网络生成 query-agnostic 的每 (layer, head, token) 重要性分数（单次会话计算，排序为 O(n log n)，逐条目带 3 字节坐标元数据，占用低于 1%）。

- **核心结果**：在默认设置（500ms 传输窗口）下，ImpactHO 达到 93.7% 平均精度，距全缓存上限（94.1%）差 0.5pp；已达到全知上界的 98.2%–99.5%，证实 myopic 调度与凸区限制的损失很小。

- **理论推导完备**：可行性判据、KKT 闭式解、加权注水结构、算法复杂度都有严格证明，提供了易于实现且高效的在线调度器。

## 8. 不足与局限

- **评估覆盖有限**：实验围绕 RULER 基准与三个模型展开，对真实用户多样化任务的泛化能力未充分证明；RULER 主要衡量长上下文理解能力，对真实的生成质量、对话能力等场景代表性不足。
- **仿真假设理想化**：采用单跳回程模型、泊松到达过程、均匀上下文分布，未考虑实际网络拓扑、回程链路多级结构、时间相关性更强的用户移动模式，真实系统可能存在性能偏差。

- **依赖重要性评分质量**：Fast KVzip 的 gating 模型可能对某些未见过的上下文或不同部署环境有泛化风险；但框架整体不依赖特定评分方法，可用其他更准确的评分替代。
