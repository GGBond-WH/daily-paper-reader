## 摘要
大规模LLM推理面临内存瓶颈。KV缓存需要每秒数百GB的数十TB容量，但目前没有内存层级能同时满足这两点。对搭载不同LLaMA模型的多代GPU系统的特性分析表明，主机内存检索相比重新计算可实现高达100倍的加速，但仅支持数十个并发长上下文用户。电学CXL池化理论上可弥合这一差距，但交换机延迟、线缆距离限制和功耗扩展问题阻碍了实际TB级部署。我们提出Marvell光子结构内存设备——一种光子-CXL混合架构，用无源光纤混洗替代电学交换机，通过无交换机的全交叉拓扑在16个主机间提供32 TB共享内存。仿真结果显示，与电学CXL池相比，延迟降低超过50%。模拟结果表明，光子结构内存设备可将多轮对话工作负载的首次令牌时间提升6.6倍，从而消除缓存逐出悬崖。

## Abstract
LLM inference at scale faces a memory wall. The KV cache demands tens of terabytes at hundreds of gigabytes per second, yet no current memory tier delivers both at once. Characterization across multi-generation GPU systems with various LLaMA models shows host memory retrieval achieves up to 100x speedup over re-computation but supports only tens of concurrent long-context users. Electrical CXL pooling theoretically bridges this gap, but switch latency, cable reach limits, and power-scaling issues prevent practical TB-scale deployments. We present the Marvell Photonic Fabric Memory Appliance, a photonic-CXL hybrid architecture replacing electrical switches with a passive fiber shuffle to deliver 32 TB shared memory across 16 hosts via a switch-free full- crossbar topology. Emulation results demonstrate over 50 percent latency reduction versus electrical CXL pools. Simulation results show that the PF Memory Appliance eliminates cache eviction cliffs by improving time-to-first-token by 6.6x for multi-turn conversations workloads.

## 1. 核心问题与整体含义（研究动机和背景）
大规模LLM推理面临严峻的“内存墙”问题：KV缓存需求高达数十TB容量和数百GB/s带宽，但现有内存层级（GPU HBM、主机DRAM、SSD）无法同时满足两者。主机DRAM容量有限（~2TB/节点），仅能支持数十个并发长上下文用户；SSD虽然容量大，但带宽比CPU-GPU低10-15倍，加载KV缓存往往比重新计算还慢。电学CXL池化理论上可弥合差距，但面临交换机延迟（70-500ns/跳）、线缆距离限制（数米）和功耗超线性扩展等问题，无法实际部署TB级共享内存。因此，需要一种同时提供大容量（>10TB）和高带宽（>100GB/s）的新型内存层级。

## 2. 论文提出的方法论
### 核心思想
用光互连（光子结构）替代电学CXL交换机，采用无源光纤混洗实现无交换机全交叉拓扑，提供确定性低延迟和线性扩展带宽。

### 关键技术细节
- **架构组成**：Marvell Photonic Fabric™ (PF) Memory Appliance，由16个PF内存模块组成，每个模块通过2.5D电光多芯片封装集成7.2Tbps光连接、2个HBM3E堆栈（共72GB，配置为直写缓存）、8个DDR5接口（共2TB DDR5）和光子集成电路（PIC）中介层。总容量32 TB，HBM3E缓存1.125 TB。
- **互联拓扑**：16×16无源光纤混洗，提供256条光路径形成全网状拓扑，16个主机可直接访问任意内存模块，无需中间交换，总光交换带宽115 Tbps。
- **主机连接**：通过光子结构NIC（PF-NIC）作为PCIe Gen6/CXL 3.1适配卡，桥接主机CXL接口到光子结构。
- **光学调制器选择**：采用GeSi电吸收调制器（EAM），兼顾热稳定性和小尺寸（<100μm），避免微环谐振器需主动波长调谐的功耗问题。
- **软件集成**：通过CXL Type-3设备枚举，Linux CXL子系统映射为Device-DAX设备；使用偏移量寻址（非虚拟指针）实现多主机共享；采用会合式一致性协议协调跨主机写入可见性；与vLLM、SGLang、NVIDIA Dynamo等框架通过现有插件接口集成（如CXL KV Connector、HiCache存储后端、NIXL后端插件）。

## 6. 论文的主要结论与发现
1. **主机内存加速上限高但容量受限**：主机内存检索相比重新计算加速最高可达100×（LLaMA-405B，100K上下文），但只能支撑数十个并发长上下文用户。

3. **PF Memory Appliance优势**：
   - 延迟：电学CXL池平均800-900ns → PF Memory Appliance平均350ns，降低超过50%。
   - 带宽：每主机128GB/s，全链路利用率100%（32B-1KB传输、线性/随机访问模式均维持）。

4. 加速比符合理论模型：\(S \propto O(n^2)/O(n)\)，随上下文长度和batch size增加而提升。
