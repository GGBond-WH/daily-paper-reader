## 摘要
Transformer广泛应用于自然语言处理、计算机视觉、网页搜索和DNA序列分析等多个领域。鉴于其广泛的适用性，提升Transformer模型的性能至关重要。然而，在注意力操作期间，处理单元与内存之间的大量数据移动严重限制了其效率。处理中内存（PIM）通过在内存内部直接执行计算来缓解这一问题。尽管先前的工作提出了基于PIM的Transformer实现，但它们存在昂贵的跨存储体通信问题，并且由于存储体容量有限而难以扩展。因此，注意力相关数据必须跨存储体分割，从而削弱了PIM的潜在优势。在这项工作中，我们提出了RED-PIM，一种算法-架构协同设计，通过将跨存储体数据移动从O(N^2)减少到O(N)，并将中间注意力矩阵从N×N缩小到d×d，从而降低注意力延迟。通过重新组织矩阵运算、本地执行计算以及采用优化的数据传输策略，RED-PIM显著降低了计算开销和互连流量。与基线PIM实现相比，RED-PIM的推理时间减少了16.05%到99.99%（几何平均值为66.42%），在较长序列上收益最大。在真实世界数据集上，RED-PIM在长文档上性能提升99.60%，在短文档上提升13.44%，同时保持或提高了准确性。这些结果证明了RED-PIM在可扩展且高效的Transformer推理中的有效性。

## Abstract
Transformers are widely used across many domains, including natural language processing, computer vision, web search, and DNA sequence analysis. Given their broad applicability, improving the performance of transformer models is critical. However, the high volume of data movement between processing units and memory during attention operations significantly limits their efficiency. Processing-In-Memory (PIM) mitigates this issue by performing computations directly inside memory. While prior work has proposed PIM-based transformer implementations, they suffer from costly inter-bank communication, and struggle to scale due to the limited capacity of memory banks. As a result, attention-related data must be split across banks, diminishing the potential benefits of PIM.   In this work, we propose RED-PIM, an algorithm-architecture co-design that reduces attention latency by minimizing inter-bank data movement from O(N^2) to O(N) and shrinking intermediate attention matrices from N x N to d x d. By reorganizing matrix operations, performing computations locally, and employing an optimized data transfer strategy, RED-PIM significantly reduces computation cost and interconnect traffic. Compared to baseline PIM implementation, RED-PIM achieves inference time reductions ranging from 16.05% to 99.99% (geometric mean of 66.42%), with the largest gains on longer sequences. On real-world datasets, RED-PIM improves performance by 99.60% for long documents and 13.44% for shorter ones, while maintaining or improving accuracy. These results demonstrate RED-PIM's effectiveness for scalable and efficient transformer inference.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- Transformer 模型在注意力操作中需要计算所有 token 对之间的得分，产生大小为 N×N 的中间注意力矩阵，导致 O(N²) 的数据移动。现代 LLM 支持超长序列（如 100 万 token），数据移动成为主要瓶颈。
- 处理中内存（PIM）技术将计算单元集成到内存内部，可减少数据在处理器与内存间的往返。然而，现有 PIM 实现受限于存储体容量（典型 HBM 存储体仅 32MB），注意力矩阵常需拆分存储，引发高昂的跨存储体通信，削弱 PIM 优势。
- RED-PIM 旨在通过算法-架构协同设计，从根本上降低注意力运算中的数据移动量，实现可扩展、高效的 Transformer 推理。

## 2. 论文提出的方法论

- **核心思想**：采用高效注意力（Efficient Attention）替代标准缩放点积注意力（SDPA），避免显式构建 N×N 注意力矩阵。先分别对 Q 和 K^T 应用 softmax，然后计算 σ(K^T)·V 得到紧凑的 d×d 矩阵 L，最后再与 σ(Q) 相乘得到最终输出。
- **数据移动优化**：将跨存储体数据移动复杂度从 O(N²) 降至 O(N)。σ(Q) 的计算完全本地化；σ(K^T) 涉及部分跨体求和（O(N/m)）；σ(K^T)·V 可在本地完成乘法后跨体聚合（O(N/m)）；最终 σ(Q) 与 L 的乘法需传递 σ(Q) 行向量（O(N/m)）。
- **架构设计**：
  - 以 FIMDRAM（HBM-PIM）为基线，每个存储体配备 PCU（含 16 位 SIMD FPU），支持本地向量乘加。
  - 采用层次化数据传输策略：先在存储体组内本地累加，再在通道内、跨通道逐级聚合，减少拥堵和延迟。
  - 设计硬件友好的 softmax：利用浮点数特性将 e^x 转换为 2^α，整数部分通过移位快速计算，小数部分用小型 LUT（0.5 KB）加线性插值近似，平均相对误差约 2.5×10⁻³，远优于泰勒展开。
- **支持大权重矩阵**：当权重矩阵无法存入单个存储体时，采用分块列分布，通过移动权重组块到 token 所在存储体进行计算，数据移动量为 3Nd²/m。

## 7. 优点

- **算法创新**：将 Efficient Attention 从计算优化引入 PIM 数据移动优化，将复杂度从 O(N²) 降至 O(N)，原理清晰。
- **架构协同**：层次化聚合策略、硬件化 softmax（基于 2 的幂次 + LUT）等设计与算法紧密配合，显著减少跨体通信。
- **实验全面**：覆盖极长序列（1M token）及多个真实数据集，与多种现有 PIM 加速器对比，并分析关键参数敏感性。
- **可扩展性讨论**：明确处理了权重矩阵无法单体存放的情况，并量化额外数据移动成本。
