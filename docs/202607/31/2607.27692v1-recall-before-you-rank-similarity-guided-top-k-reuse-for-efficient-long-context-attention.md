## 摘要
Top-K 稀疏注意力通过仅关注少量键值（KV）条目来降低 Softmax 和值聚合的成本。然而，识别这一子集仍需要对完整 KV 缓存中的当前查询进行评分，并执行全局 Top-K 选择，这使得选择器的成本随上下文长度线性增长，限制了稀疏注意力在长上下文解码中的实际效率。本文提出了 ReTopK，一种无需训练的方法，通过复用历史检索决策来加速动态 Top-K 注意力。ReTopK 基于以下观察：相似的查询通常会关注重叠的支持集，且部分重叠的支持集仍能保留大部分精确 Top-K 注意力质量。对于每个注意力头，它维护一个有界的历史查询-支持对缓存，为每个新查询检索最相似的缓存查询，将存储的支持集与最近的窗口取并集，并仅使用精确的当前查询分数对得到的紧凑候选集进行重排序。当复用不可靠时，基于相似性的回退机制会调用全历史精确 Top-K，而定期的精确刷新则限制缓存漂移。ReTopK 保留完整的 KV 缓存，仅复用选定的索引，而非历史分数、注意力权重或输出。在 16K\--128K 的上下文环境中，ReTopK 在评估的近似方法中取得了最低的 PG19 困惑度，以及最高的 NIAH 和 LongBench 分数。在 128K 上下文中且 $K=512$ 时，ReTopK 相较于精确 Top-K 仅增加 0.50% 的困惑度，同时将注意力计算加速了 $3.07\times$。

## Abstract
Top-$K$ sparse attention reduces the cost of Softmax and value aggregation by attending to only a small subset of key--value (KV) entries. However, identifying this subset still requires scoring the current query against the full KV cache and performing global Top-$K$ selection, leaving selector cost linear in context length and limiting the practical efficiency of sparse attention for long-context decoding. In this paper, we introduce ReTopK, a training-free method that accelerates dynamic Top-$K$ attention by reusing historical retrieval decisions. ReTopK builds on the observation that similar queries often attend to overlapping supports and that partially overlapping supports can still preserve most of the Exact Top-$K$ attention mass. For each attention head, it maintains a bounded cache of historical query--support pairs, retrieves the most similar cached queries for each new query, unions their stored supports with a recent window, and reranks only the resulting compact candidate set using exact current-query scores. A similarity-based fallback invokes full-history Exact Top-$K$ when reuse is unreliable, while periodic exact refreshes limit cache drift. ReTopK retains the complete KV cache and reuses only selected indices, rather than historical scores, attention weights, or outputs. Across 16K--128K contexts, ReTopK achieves the lowest PG19 perplexity and the highest NIAH and LongBench scores among the evaluated approximate methods. At 128K with $K=512$, ReTopK incurs only a 0.50\% perplexity increase over Exact Top-$K$ while accelerating attention computation by $3.07\times$.

## 1. 核心问题与整体含义

- **背景**：大语言模型（LLM）在长上下文解码时，注意力机制的 QK 计算和 KV 缓存访问代价随上下文长度线性增长。Top-K 稀疏注意力虽然只对 K 个最高分值条目做 Softmax 和值聚合，但**识别这 K 个条目**仍需对完整 KV 缓存打分并做全局 Top-K 选择，因此“选择器”（selector）成本依然是线性增长的，成为实际瓶颈。
- **核心问题**：能否在不扫描全部历史 KV 的前提下，动态地为每个查询恢复其专属的稀疏支持集（support），从而真正加速长上下文稀疏注意力？
- **整体含义**：论文抓住“相似查询往往对应重叠的注意力支持集”这一观察，提出通过复用历史检索决策来避免每次解码都做全历史 Top-K 选择，为高效长上下文推理提供了新的“先回忆、再排序”范式。

## 2. 方法论：ReTopK

- **核心思想**：历史查询与其选定的 Top-K 索引（support）构成缓存条目；新查询先与缓存中的历史查询做相似度匹配，取最相似的 R 个历史查询的 support 并集，再加入近期窗口作为候选集；然后用当前查询对这些候选键精确打分并重排序，得到最终 Top-K 支持集。只复用“历史索引”这一检索决策，不复用历史分数、注意力权重或输出。
- **关键模块**：
  - **查询-支持缓存**：每个注意力头维护一个有界 FIFO 缓存，容量为 C，存归一化查询向量及其对应支持集索引。
  - **相似性召回**：计算当前查询与缓存中 C 个历史查询的余弦相似度，取 Top-R 个。
  - **候选构建**：将 R 个历史支持集与最近 W 个 token 的窗口取并集，得到紧凑候选集 $A_t$，大小 $M_t \le RK+W \ll L_t$。
  - **精确重排序**：只对候选集计算当前查询的 QK 分数，再做 Top-K 选择。
  - **回退机制**：若最大相似度 $\rho_t^{\max} < \tau$，则回退到全历史精确 Top-K。
  - **周期刷新**：每隔 $T_r$ 步执行一次精确 Top-K，以限制缓存漂移。
- **公式化流程**（文字说明）：Step 1 维护缓存 $B_t=\{(\bar q_c,\hat S_c)\}$；Step 2 计算 $\rho_{t,c}=\bar q_t^\top \bar q_c$ 并取 Top-R；Step 3 构造 $A_t=\text{Unique}(\cup_{c\in R_t}\hat S_c \cup \mathcal{L}_t)$；Step 4 对 $A_t$ 计算精确分数 $\hat e_{t,i}$ 并选 Top-K；Step 5 用所选支持做稀疏 Softmax-值聚合；Step 6 更新缓存。路径选择规则：$P_t=\text{Exact}$（当 $T_r>0$ 且到达刷新时刻，或 $\rho_t^{\max}<\tau$），否则 Reuse。
- **复杂度**：复用步选择器成本为 $O(Cd + RK + M_t d)$，与上下文长度无关，而精确 Top-K 为 $O(L_t d + L_t)$。

## 6. 主要结论与发现

- ReTopK 在 128K、K=512 时，相对 Exact Top-K 仅增加 0.50% 困惑度，注意力计算加速 3.07 倍；在 16K\~128K 上的 PG19 PPL 为近似方法中最低，NIAH 和 LongBench 分数最高或持平。
- 跨模型验证表明配置无需调整即可迁移，速度提升为 1.26\~2.66 倍，质量损失可控。
- 支持集复用虽不能完全复现精确 Top-K 索引，但保留的注意力质量高（平均保留 92.4% 注意力质量，输出余弦 97.4%），说明低质量索引对最终输出的影响较小。
- 相似性回退和周期刷新共同保障长程稳定性：8K 延续内 PPL 偏差有界，无后期误差激增。
- 内核融合显著提升实际性能（L1→L5 提速 2.29\~2.57 倍）；端到端解码中，随着上下文长度增大（128K→5M），非注意力部分占比下降，ReTopK 相对精确 Top-K 的端到端加速从 1.13 倍提升到 3.73 倍。
- 核心结论：检索决策复用可以避免全历史索引发现，且不牺牲太多精度，为超长上下文稀疏注意力提供了一种无需训练的新路径。

## 7. 优点

- **问题洞察准确**：明确指出“稀疏注意力但索引发现不稀疏”的矛盾，并量化了 QK+Top-K 选择在总时延中的占比。
- **方法设计巧妙**：只复用“索引”而非分数或输出，避免了历史信息污染；候选并集+重排序保证了当前查询的主导性；回退+刷新双保险提高可靠性。
