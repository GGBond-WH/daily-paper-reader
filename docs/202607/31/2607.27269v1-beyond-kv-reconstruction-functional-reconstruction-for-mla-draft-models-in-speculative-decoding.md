## 摘要
多头潜在注意力（MLA）对于长上下文大语言模型推理日益重要，因为紧凑的潜在状态替代了不断增长的键值（KV）缓存，并减少了解码内存流量。然而，大多数有能力的开源检查点使用多头或分组查询注意力（MHA/GQA），因此需要进行转换以获得MLA的缓存效率，而无需从头重新训练。推测解码提供了互补的加速，但其加速取决于草稿提议与目标验证之间的一致性。我们发现，直接的MHA/GQA到MLA转换会显著降低这种一致性：低秩分解和RoPE处理引入了注意力函数误差，这些误差对于独立生成可能可以容忍，但会大幅降低草稿令牌的接受率。因此，我们将MLA草稿构建表述为功能性重建而非缓存压缩。我们的端到端（E2E）方法优化每个转换后的MLA注意力模块，以在校准隐藏状态上复现其原始MHA/GQA对应模块的输出投影后响应。这种与转换器无关的转换后过程保留了转换后的缓存和推理图，并且既不需要验证器logits也不需要验证器监督。我们评估了192种模型-转换器-后端-方法-任务配置，涵盖四个Llama/Qwen草稿-目标对、TransMLA和MHA2MLA、HF和vLLM，以及四个200提示任务。在0.5个百分点的报告容忍度下，功能性重建在64个匹配任务单元中的37个中实质性提高了接受率，26个基本保持不变，1个实质性下降。代码和评估工件可在https://github.com/swyhahaha/FunctionalMLA获取。

## Abstract
Multi-head latent attention (MLA) is increasingly important for long-context LLM inference because compact latent states replace the growing key-value (KV) cache and reduce decoding memory traffic. Yet most capable open checkpoints use multi-head or grouped-query attention (MHA/GQA), so conversion is needed to obtain MLA's cache efficiency without retraining from scratch. Speculative decoding offers complementary acceleration, but its speedup depends on agreement between draft proposals and target verification. We find that direct MHA/GQA-to-MLA conversion can sharply reduce this agreement: low-rank factorization and RoPE handling introduce attention-function errors that may be tolerable for standalone generation but substantially lower draft-token acceptance. We therefore formulate MLA draft construction as functional reconstruction rather than cache compression. Our end-to-end (E2E) method optimizes each converted MLA attention module to reproduce the post-output-projection response of its original MHA/GQA counterpart on calibration hidden states. This converter-agnostic post-conversion procedure preserves the converted cache and inference graph and requires neither verifier logits nor verifier supervision. We evaluate 192 model-converter-backend-method-task configurations spanning four Llama/Qwen draft-target pairs, TransMLA and MHA2MLA, HF and vLLM, and four 200-prompt tasks. With a 0.5-percentage-point reporting tolerance, Functional Reconstruction materially improves acceptance in 37 of 64 matched task cells, leaves 26 practically unchanged, and materially decreases one. Code and evaluation artifacts are available at https://github.com/swyhahaha/FunctionalMLA.

### 1. 核心问题与研究动机

- **背景**：大语言模型推理的瓶颈正从计算转向内存访问。自回归解码时，每次生成 token 都需要读取不断增长的 KV 缓存，因此推理延迟和吞吐量高度依赖缓存的高效表示。
- **MLA 的优势**：多头潜在注意力（MLA）在 DeepSeek 系列模型中被采用，它用低维潜在向量代替显式 KV 缓存，并通过吸收投影计算注意力，大幅降低内存流量。但大多数已有的开源模型（如 Llama、Qwen）是基于 MHA/GQA 预训练的，因此需要将 MHA/GQA 转换为 MLA 以享受缓存效率，同时避免昂贵的从头重训练。
- **提出的问题**：论文发现直接进行 MHA/GQA→MLA 转换存在一个容易被忽略的失败模式——转换后的 MLA 模型可能是一个“高效但低质”的**草稿模型**。在推测解码中，草稿模型需要与目标模型高度一致（token 接受率高），而转换引入的注意力函数误差虽然对独立生成影响不大，却会显著降低草稿接受率。
- **核心主张**：MLA 草稿构建应该被视为一个**功能性重建问题**，而非简单的缓存压缩问题。结构上有效的转换并不等于功能上保真、更不等于推测解码中有用。

### 2. 方法论

#### 核心思想

- **E2E 功能重建**：将转换后的 MLA 注意力模块训练为复现原始 MHA/GQA 注意力模块的输出投影后响应（post-WO response）。即让转换后的 MLA 模块在相同输入（校准隐藏状态）下，产生与原始 GQA 模块尽可能一致的输出。
- **与转换器无关**：该方法不依赖特定的转换方式，可以应用于 TransMLA 和 MHA2MLA 两种转换初始化的产物。

#### 关键公式与流程

- **GQA 注意力基本形式**：
  `s_tij = q_t,i^T R_tj k_j,g(i) / √d_k`
  `a_tij = softmax(s_tij)`
  `o_t,i = Σ_j a_tij v_j,g(i)`
  其中 `R_tj` 为 RoPE 相对旋转矩阵。

- **MLA 的低秩瓶颈**：MLA 将键和值压缩为低秩潜在状态：`c_j = W_DKV h_j`，重建键/值需要通过 `W_UKV` 上投影。精确等价要求 `rank([W_K,nope; W_V]) ≤ r`，当此条件不满足时，任何给定秩的压缩分解都会留下残差。

- **RoPE 处理误差**：论文推导了转换后 logit 与原始 logit 的精确差值公式，分解为保留键重建误差、位置路径误差、查询扰动项及其交互项。软极大将 logit 残差映射为注意力权重误差，再经值聚合和输出投影放大。

- **推测解码的接受率指标**：
  - 随机采样下：`α_sample(x) = 1 − TV(p_D^x, p_T^x)`
  - 贪心解码下：`α_greedy(x) = 1[argmax_y p_D^x(y) = argmax_y p_T^x(y)]`

- **E2E 损失函数（核心优化目标）**：

  `L_E2E^(ℓ) = E_b[ || M_b ⊙ (A_MLA^ℓ(H_ℓb) − sg[A_orig^ℓ(H_ℓb)]) ||_F² / (D · Σ_t M_b,t) ]`

  - `sg` 表示停止梯度（stop-gradient）；
  - `A^ℓ` 是经过固定输出投影后的注意力层输出；
  - `M_b` 是有效 token 掩码；
  - 只更新转换器引入的 query 和 KV 投影，输出投影（WO）保持冻结；
  - 校准隐藏状态由真实模型前向传播缓存获得。

#### 算法流程

1. 用 TransMLA 或 MHA2MLA 将原始 MHA/GQA 检查点转换为 MLA 初始化；
2. 将原始 GQA/MLA 块和转换后的 MLA 块并行，输入相同的校准隐藏状态；
3. 计算两者 post-WO 输出的掩码均方误差；
4. 通过冻结原始路径、仅更新转换引入的 query/KV 投影来优化这一损失；
5. 逐层独立优化，无需验证器模型参与。

### 3. 实验设计

#### 数据集 / Benchmark

使用了四个代表性任务，每个任务固定 200 题提示（HumanEval 为 164 个规范题目加 36 个确定性重复）：

| 任务 | 类型 |
|---|---|
| HumanEval | 代码生成 |
| Alpaca | 指令跟随 |
| Natural Questions (NQ) | 开放域问答 |
| CNN/DailyMail (CNN/DM) | 摘要 |

#### 模型与转换配置

- **草稿→目标对**四个：Llama-1B→Llama-8B、Llama-3B→Llama-8B、Qwen-1.5B→Qwen-7B、Qwen-3B→Qwen-7B。
- **转换方法**两种：TransMLA、MHA2MLA。
- **推理后端**两种：Hugging Face（HF）、vLLM。
- **对比方法**三种：
  1. **Original GQA**：未转换的原始草稿（参考基准）；
  2. **Partial RoPE**：匹配转换器局部重建基线；
  3. **Functional Reconstruction（Ours）**：论文提出的 E2E 功能重建——从相同转换初始化出发，保持相同的注意拓扑、潜在缓存预算和推理接口，仅优化 E2E 目标函数。

#### 解码参数

- BF16、batch size 1、贪心解码、固定种子 42；
- 草稿长度 γ：1B/1.5B 使用 γ=4，3B 使用 γ=3；
- 最大生成长度 128 tokens。

### 6. 主要结论与发现

#### 核心结果

- **在 64 个匹配任务单元中**：
  - 37 个出现实质性接受率提升；
  - 26 个基本不变；
  - 1 个实质性下降（Qwen-3B + TransMLA + vLLM 的 CNN/DM，−0.55 pp）;
  - 即 37/38 的容差外变化有利于功能重建。

#### 关键发现

1. **转换与草稿是不同目标**：结构有效的转换可能在推测解码中表现很差，独立生成质量不能代表草稿质量。

2. **模型家族与转换器的交互效应**：
   - Llama + TransMLA：全部 16 个单元都提升（+0.68 到 +4.23 pp）；
   - Llama + MHA2MLA：全部 16 个单元不变；
   - Qwen + MHA2MLA：15/16 提升；
   - Qwen + TransMLA：6 个提升、9 个不变、1 个下降。
   - 这说明转换器的初始化决定了可修复的功能残差空间，功能重建的有效性与转换器和模型家族的匹配有关。

3. **后端影响局部化**：HF 下 20 个单元提升、12 个不变；vLLM 下 17 个提升、14 个不变、1 个下降。差异主要集中在 Qwen-TransMLA 组合。

4. **恢复有限**：功能重建能部分恢复转换损失，但通常无法完全恢复到原始 GQA 接受水平。在严重不匹配的转换器-后端路径下，残差依然很大（如 Qwen-3B-TransMLA-vLLM 的 NQ 从原始 71.03% 降至 Partial 的 10.95%，Ours 仅恢复到 12.73%）。

5. **吞吐量**：37 个接受率提升的单元中，12 个也出现实质性吞吐提升、24 个基本不变、1 个变慢。改进接受率不要求额外推理操作或改变缓存预算。

### 7. 优点

1. **问题视角新颖**：将“功能重建”与“结构转换”明确区分，揭示了推测解码场景下 MLA 转换独有的失败模式，填补了现有研究空白。

2. **方法简洁且通用**：E2E 功能重建不依赖验证器 logits、不改变缓存结构、不增加推理开销，适用于不同转换器、模型家族和后端。

3. **目标函数设计合理**：post-WO 输出匹配（而非投影级匹配）直接度量完整注意力函数的等价性，避免了局部误差的误导性；stop-gradient 冻结原始路径，训练稳定。

4. **实验设计严谨**：0.5 pp 的容差设置增强了报告的可信度，控制了微小差异的过度解读；Partial-Ours 对比保持所有结构参数不变，精确隔离了重建目标的影响。

5. **诚实报告局限**：论文坦诚报告了唯一的性能下降案例和恢复不充分的情况，没有选择性地隐藏负面结果。

6. **跨因子分析深入**：从模型家族、转换器、后端、草稿大小、任务类型五个维度拆解结果，揭示了各种交互效应，比单纯报告汇总数字更有洞见。

---

### 8. 不足与局限

1. **规模有限**：模型不超过 8B，缺乏大规模目标模型（如 70B+）的验证；任务类型仅四类且生成长度 128 token，没有覆盖长文档/长上下文场景。

2. **统计验证不足**：单一种子、每次配置一次评估，没有置信区间或多次重复测量；0.5 pp 容差是描述性阈值而非统计显著性检验。

3. **吞吐量结果存疑**：vLLM 下 TransMLA 使用 TP2 而 MHA2MLA 使用 TP1，两种后端的绝对吞吐量不可直接比较；吞吐差异未与接受率改进严格区分，存在运行波动可能。

4. **恢复能力有限**：功能重建通常只能部分恢复转换损失，且在严重不匹配的转换器/后端路径下改进甚微——方法不能弥补低秩信息损失或运行时实现错误。

5. **层间独立优化**：每层独立最小化局部 MSE，未考虑层间的交互放大/衰减效应；局部最优不保证全局接受率最优（论文在讨论中承认这一点）。

6. **未与更优草稿方法对比**：没有与 EAGLE、Medusa、自推测解码等相比，无法判断功能重建的草稿是否在绝对性能上优于其他范式。

7. **超参数敏感性未知**：校准状态的数量、来源、层优化顺序等超参数未进行敏感性分析；论文只报告了单一设置。

8. **部署适配问题**：训练使用的模块与实际部署内核（尤其是 vLLM 的张量并行语义）可能存在差异，导致学习到的修正不能完全在部署中体现。

### 总结

这篇论文提出了一个针对 MLA 转换模型在推测解码场景下的**端到端功能重建**方法。它本质上是一种训练时后处理优化：在固定转换结构的前提下，通过让转换后的 MLA 模块复现原始 GQA 注意力模块的输出投影后行为，来提高草稿模型与目标模型的一致性。实验表明该方法在大多数配置下能提升草稿接受率，且不增加推理开销。不过，其验证规模、统计严谨性和恢复能力仍有提升空间。论文最重要的贡献在于将“结构有效性转换”与“功能保真草稿构建”明确区分开来，提出了一种泛化能力较强的修复方案，并系统性地刻画了不同转换器-模型-后端的交互效应。
