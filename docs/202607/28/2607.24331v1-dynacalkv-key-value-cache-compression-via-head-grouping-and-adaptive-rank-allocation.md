## 摘要
随着大语言模型（LLM）推理阶段需要处理长上下文窗口，键值（KV）缓存最初似乎能应对这一挑战，但随着上下文窗口不断增长，它最终成为一个显著的瓶颈。最近，低秩压缩作为一种有效减少KV缓存内存同时保持模型性能的方法被研究。然而，现有方法中只有少数区分了键缓存和值缓存的处理，尽管它们的作用不同。此外，这些方法通常采用固定的注意力头分组，这可能无法充分利用注意力头之间的结构相似性。本文提出了一种改进的低秩KV缓存压缩框架。对于键缓存，我们基于中心核对齐（CKA）相似性动态分组注意力头，并在参数预算下自适应分配秩预算。对于值缓存，我们采用与ReCalKV相同的方法，通过离线校准优化低秩分解以提高重建质量。在三个经过指令微调的LLM上的实验结果表明，我们的方法在保持竞争性精度的同时减少了键缓存的参数量。我们进一步观察到，所提出的策略对于多头注意力（MHA）模型特别有效，而对于分组查询注意力（GQA）模型，尤其是在长上下文设置中，应更保守地应用。

## Abstract
As the inference phase of Large Language Models (LLMs) requires handling long context windows, the Key-Value (KV) cache initially appears to address this challenge but eventually becomes a significant bottleneck as the context window continues to grow. Low-rank compression has recently been studied as an effective approach to reduce KV cache memory while maintaining model performance. However, only a few existing methods treat the Key and Value caches differently, despite their distinct roles. Moreover, these methods typically employ fixed attention-head grouping, which may not fully exploit the structural similarity among attention heads. In this paper, we propose an improved low-rank KV cache compression framework. For the Key cache, we dynamically group attention heads based on Centered Kernel Alignment (CKA) similarity and allocate the rank budget adaptively under a parameter budget. For the Value cache, we adopt the same approach as ReCalKV, refining the low-rank decomposition through offline calibration to improve reconstruction quality. Experimental results on three instruction-tuned LLMs show that our method reduces the number of Key cache parameters while maintaining competitive accuracy. We further observe that the proposed strategy is particularly effective for Multi-Head Attention (MHA) models, whereas it should be applied more conservatively to Grouped-Query Attention (GQA) models, especially in long-context settings.

- **问题背景**：大语言模型（LLM）推理时，长上下文窗口导致KV缓存（Key-Value cache）内存线性增长，成为关键瓶颈。低秩压缩虽能减少内存，但现有方法大多未区分Key和Value的不同作用，且采用固定大小的注意力头分组，无法充分利用头间结构相似性。
- **研究动机**：提出一种改进的低秩KV缓存压缩框架，通过动态分组和自适应秩分配，在保持模型性能的同时进一步减少Key缓存参数量，并探究不同注意力架构（MHA vs. GQA）下的适用性。

## 二、方法论
- **核心思想**：
  - 对**Key缓存**：基于Centered Kernel Alignment（CKA）相似性动态分组注意力头（聚簇），并根据组内能量（奇异值平方和）自适应分配秩预算，同时确保总参数不超过ReCalKV方法。
  - 对**Value缓存**：沿用ReCalKV方法，对整个投影矩阵做SVD低秩分解，再通过离线校准数据最小化重建误差，以优化分解因子。
- **关键技术细节**：
  1. **层间秩分配**：借助Palu方法，利用Fisher信息分数在层间分配秩预算。
  2. **Key压缩流程**（Algorithm 1）：
     - 输入：Key投影矩阵 \(W^{(k)}\)，CKA相似矩阵 \(S\)，秩预算 \(r\)，候选簇数 \(K\)。
     - 对每个候选 \(K\)，用聚合聚类（Agglomerative Clustering）将头分组。
     - 初始化各组秩 \(r_i\) 正比于组能量并取整。
     - 通过贪心调整（每次减少能量/\(\alpha_i\) 最小的组的秩）满足参数约束 \(\sum_i r_i \alpha_i \leq 4r/h\)。
     - 用目标函数（重建误差 + \(\lambda\) × 未使用秩惩罚）选择最优 \(K^*\)（\(\lambda=1\)）。
  3. **Value压缩**：SVD后，用校准数据 \(X\) 改进左因子 \(L_v\) 和右因子 \(R_v\) 的闭式解（最小化 \(\|L_v R_v X - W^{(v)}X\|_F^2\)）。
- **公式**（文字说明）：
  - 参数约束：\(\sum_i r_i \alpha_i \leq 4r/h\)（\(\alpha_i\) 为组内头比例，\(h\) 为总头数）。
  - 目标函数：\(\sum_i \|W_i - L_i R_i\|_F^2 + \lambda (r - \sum_i r_i)\)。
  - Value因子更新：\(L_v = W^{(v)} X X^\top R_v^\top (R_v X X^\top R_v^\top)^{-1}\)，类似更新 \(R_v\)。

## 六、主要结论与发现
1. **参数减少**：DynaCalKV显著减少Key缓存参数量，对SmolLM2减少65.23%，对Llama-3.2减少18.23%，对Qwen1.5减少16.00%。
2. **零样本性能**：在简单常识任务（PIQA, ARC-e）上提升；在复杂推理任务上略有下降（0.28%~3.00%）；SmolLM2上平均增益+0.44%。
3. **长上下文性能**：
   - 对Qwen1.5（MHA）几乎无损失（平均-1.02%）。
   - 对Llama-3.2（GQA）大幅下降（平均-8.03分），尤其影响检索和摘要任务。
4. **架构差异**：动态分组对MHA（多头）模型非常有效，但对GQA（少头）模型需谨慎，尤其在长上下文中易过度压缩导致关键信息丢失。
