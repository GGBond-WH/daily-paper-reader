## 摘要
长周期智能体越来越多地将其KV缓存复用为记忆：服务系统保留一部分缓存条目，丢弃其余部分。因此，驱逐和情景记忆方案基于一个很少直接检验的前提，即一旦产生某个事件的观测消失，该保留的事件仍具有信息价值。我们通过从服务内容中省略一个早期观测，来测试这一前提（保持其他代理历史相同）。在那些对该观测敏感的条目中，答案绝大多数跟随被省略的值，尽管没有任何服务片段说明哪个值是正确的。我们称之为语义物化：下游事件缓存的行充当一种独立可服务的计算视图，而这些计算的输入已消失。它也可以被有意写入。一个刻意措辞、不含答案的事件，在Qwen3-8B上将“与捐赠者一致的恢复”从6%提升至51%，而从未明确提及该值；相反，从长期对话中被动收集自然提及则未发现任何优势。这样的行所携带的信息是具体且有限的。紧凑的状态得以存活，较大的负载则趋近于随机水平，而一个构造是否写入取决于措辞而非仅仅含义，因此模型同等理解的两个措辞可能产生截然不同的结果。结果是针对稀疏事件-KV服务的内存契约：写什么，它落在哪里，以及一旦来源消失后什么能幸存。对于任何执行驱逐的人来说，推论是：丢弃一个来源事件且未观察到精度下降，并不能证明该来源是不必要的。

## Abstract
Long-horizon agents increasingly reuse their KV cache as memory: a serving system keeps a subset of cached entries and drops the rest. Eviction and episodic-memory schemes therefore rest on a premise rarely tested directly, that a retained event is still informative once the observations that produced it are gone. We test it by omitting one earlier observation from what is served, across otherwise identical agent histories. Among items sensitive to that observation, the answer overwhelmingly follows the omitted value, though no served span says which value is correct. We call this semantic materialization: a downstream event's cached rows act as an independently servable view of computation whose inputs are gone. It can also be written on purpose. A deliberately phrased, answer-free event raises donor-aligned recovery from 6% to 51% on Qwen3-8B without ever naming the value, whereas passively harvesting natural mentions from long-term dialog yields no detected advantage. What such a row carries is specific and bounded. Compact state survives, larger payloads decay toward chance, and whether a construction writes at all turns on phrasing rather than on meaning alone, so two phrasings the model comprehends equally well can diverge sharply. The result is a memory contract for sparse event-KV serving: what to write, where it lands, and what survives once the source is gone. For anyone who evicts the corollary is that dropping a source event and observing no accuracy loss does not show the source was unnecessary.

## 论文的核心问题与整体含义（研究动机和背景）

- **背景**：长周期智能体（long-horizon agents）越来越多地将原始交互历史——更激进地，是将读取历史时产生的KV缓存——作为记忆基质。服务这种记忆必然是**稀疏的**：未来查询只触及少数事件，因此系统会选择少数片段（缓存行）并丢弃其余部分，包括通常产生这些值的观测。
- **核心问题**：现有驱逐和情景记忆策略仅验证下游精度，但**不隔离保留片段是否仍携带来自已驱逐源事件的状态**。作者提出一个问题：一个被保留的下游事件片段，其文本不包含答案，但其KV缓存行可能已经编码了来自已删除源事件的计算结果——即**语义物化**（semantic materialization）。能否利用这种现象？它的边界是什么？
- **整体含义**：稀疏事件-KV服务本质上**不仅仅是行上的检索**；被选择保留的行可能携带“看不见的信息”。因此，驱逐一个源事件而未观察到精率下降**并不证明该源不必要**，因为其状态可能已经“物化”到了下游事件中。论文由此提炼出一套**内存契约**：写什么（trigger）、写在哪里（landing）、什么能存活（access）。

## 论文提出的方法论：核心思想、关键技术细节、算法流程

### 核心思想
- **语义物化**：在单一全局预填充（global prefill）中，下游事件（如“M mirrors S”）会通过因果注意力机制，在它的KV缓存行中编码上游源事件（如“S is ONLINE”）的状态。即使服务时丢弃源事件，只保留下游事件的KV行，模型仍能基于这些行恢复被省略的值。
- **捐赠者对（donor pair）**：构建两个仅在省略的源事件值上不同的轨迹（如S=ONLINE vs. S=OFFLINE），其他所有被服务的token和位置完全相同。通过对比两个下游事件的KV行对答案的影响，可以因果地测出语义物化。

### 关键技术细节
1. **服务契约**：
   - (i) 定义问题的源事件被排除在服务集之外；
   - (ii) 写时（预填充时）不知道未来具体查询的措辞，但可预期谓词/目标模式；
   - (iii) 不辅助训练适配器或微调，只使用冻结模型的自然接口。
2. **触发（Trigger）**：哪些事件能写入状态？作者构建了16种构造（8种镜像关系，8种标记关系），评估其“写入通过率”（write-through rate）：在省略源事件、仅服务载体行时，模型正确恢复值的概率。发现**触发取决于表面形式而非仅仅是语义**，且不同模型具有不同“写入孔径”（aperture）。
3. **着陆（Landing）**：物化状态存在哪里？在引用链（source→root→edge）中，**根事件（root）承载主导的捐赠者一致信号**，而引用边（reference edge）主要将查询路由回根事件。服务集和措辞也会影响着陆。
4. **访问（Access）**：能恢复多少状态？**二进制状态恢复很好（~0.934）**，四路和八路负载接近随机，三位数字负载完全无法恢复。派生结论（derived verdicts）在写时提示下可以提升，但数字负载不行。

### 算法流程（文字说明）
1. 构建事件序列 \(T = (e_1, ..., e_n)\)，进行一次全局预填充，得到每个事件 \(e_i\) 的KV缓存 \(\text{KV}(e_i)\)。
2. 在服务时，选择子集 \(\Sigma \subseteq T\) 作为服务集（包括需要的下游事件，但排除源事件）。
3. 对于每一个“捐赠者对”，构建两个轨迹，其中源事件的值不同（如ONLINE vs. OFFLINE），但服务集和查询位置完全相同。
4. 将服务集的行重新组装（保持原始位置ID，除非使用滑动窗口模型时保持原生位置），然后追加查询，让模型生成答案。
5. 对比两个捐赠者轨迹下的答案是否跟随被省略的源值：计数“follow”（一致）vs.“anti”（相反）vs.“const”（相同）等。
6. 针对不同构造、模型、服务设置（根事件是否单独、是否包含下游提及、服务位置等）重复测量。

## 实验设计：使用的数据集、场景、benchmark、对比方法

### 合成轨迹（主要控制实验）
- **场景**：模拟智能体在日志中记录传感器状态，比如“register S is ONLINE”，然后下游事件“M mirrors S”（无值），再问“M的状态是什么？”。
- **数据集**：随机生成包含24个事件的日志，源事件在中间，下游根事件和提及事件在后续。每个条目的二进制值、四路、八路随机赋值。
- **Benchmark**：主要基准是**捐赠者对比较**，对比不同服务集、不同构造、不同模型下的“follow”比例。还比较了“显式文本”上界（完全包含答案）和“被动自然提及”下界。
- **对比方法**：
  - 不同载体构造（16种）与全文本控制（full-text comprehension control）。
  - 不同服务集：root-only、mention-absent、mention-co-served、edge-only等。

### 真实对话（自然对话压力测试）
- **数据集**：REALTALK（21天长对话，10个对话session）和LoCoMo（多种长时对话，10个session）。

## 论文的主要结论与发现

1. **语义物化存在且方向稳定**：在捐赠者敏感的条目中，答案99:0跟随被省略的源值，尽管服务文本从未提及该值（Qwen3-8B）。这一方向在多个模型、服务设置和读方式下持续不变。
2. **可编程性**：故意编写的不含答案的计算指令（如“determine the verdict now and record it here”）可将捐赠者一致恢复率从6%提升到51%（Qwen3-8B），且不影响其他泄漏控制。被动自然提及则无任何好处。
3. **内存契约的三要素**：
   - **触发**：由表面形式而非含义决定；不同模型具有不同的写入孔径，不存在通用构造。
   - **着陆**：根事件承载主导信号，引用边主要路由查询回根；服务集中其他行和位置会影响着陆。
   - **访问**：紧凑状态（二进制）恢复良好；大负载（四/八路、数字）消退至随机；派生结论需要写时提示才能恢复。
4. **对驱逐的推论**：丢弃源事件而未损失精度不能证明源不必要——可能其状态已物化到下游行中。
5. **更新成本低**：通过附加p-token补丁修正状态成本O(pL+p²)远优于重计算O(L²)，但需注意版本化和查询范围。

## 优点：方法或实验设计上的亮点

- **因果识别设计**：捐赠对通过字节水平控制（仅改变源事件值，服务token和位置完全一样），干净地隔离语义物化的存在，避免文本自包含答案或模型先验的混淆。
- **多维度系统测量**：不仅报告一个数字，而是系统变化触发构造、着陆位置、访问类型、服务集、模型、读方式等。
- **控制泄漏和回声**：每个实验都包含泄漏断言（服务行不包含答案token或操作数）、无关查询回声控制（材料化不会泄漏到无关查询）。
- **统计严谨**：使用Wilson置信区间、McNemar配对检验、双单侧等价检验（TOST）、对话簇自举；排除边界情况（如相同描述、不同评分行）。
- **在真实对话中测试**：尽管未观察到增益，但直接挑战了自然对话设定下语义物化的实用性，为实践者提供了明确边界。

## 不足与局限

- **紧凑状态上限**：只对二进制状态有效；大负载（数字、多分类）几乎无法恢复，派生结论需写时提示且可能降低全文本精度。**不能作为通用信息通道**。
- **真实对话中无优势**：被动自然提及无法产生可检测的增益，且注入式正面控制（same-path injected carrier）仅在Gemma-4部分成功。因此语义物化目前主要适用于精心设计的合成场景。
- **模型依赖性**：没有一种构造在所有模型上都是“W”类（写入类），写入孔径因模型而异；自由生成与logit探测读方式可能不一致，需逐个校准。
- **滑动窗口模型几何失真**：对于Gemma-4（40/48层是局部滑动窗口），紧凑路径（重打包到相邻槽位）不匹配原生位置掩码，导致长序列结果偏差，因此真实对话实验采用了原生位置掩码服务。这在应用时需要特别注意。
- **实验范围限制**：
  - 仅在冻结模型上测试，未涉及微调或模型压缩。
  - 未测试线性注意力混合体（如Qwen3.6），因无法逐层提取token可寻址的KV。
  - 真实对话的REALTALK仅10个对话，统计推断依赖LoCoMo。
- **负面结果的性质**：任何可访问性负面结论都是针对输出接口的测量，不能排除表示层面的隐含信息（论文也承认这一点，称表示层面探测是悬而未决的仲裁者）。
